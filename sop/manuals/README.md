# 用户操作手册

> 本手册面向最终用户，介绍低代码管理平台的日常操作方法。

## 阅读对象

- 系统管理员
- 业务配置人员
- 普通业务用户

## 快速开始

1. 打开浏览器，访问系统地址
2. 使用管理员分配的账号密码登录
3. 通过左侧菜单进入对应功能模块

更多细节请按顺序阅读：
1. [系统简介](overview.md)
2. [登录与退出](getting-started/login.md)
3. [首页与导航](getting-started/homepage.md)
