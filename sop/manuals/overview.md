# 系统简介

## 什么是低代码管理平台

低代码管理平台是一套通过可视化配置快速生成业务功能的系统。用户无需编写大量代码，即可通过「数据模型 + 表单 + 列表」配置出满足业务需求的增删改查页面。

## 主要功能模块

| 模块 | 说明 |
|------|------|
| 系统管理 | 管理用户、角色、菜单、部门、字典等基础数据 |
| 在线开发 | 通过数据模型、表单设计器、列表设计器、自定义页面设计器生成业务功能 |
| 消息中心 | 发送与接收站内消息，管理消息模板 |
| 系统监控 | 查看服务器信息、在线用户、操作日志 |

## 常用术语

| 术语 | 说明 |
|------|------|
| 数据模型 | 对应数据库中的一张业务表，例如「客户」「订单」 |
| 字段 | 模型中的列，例如客户表中的「客户名称」「联系电话」 |
| 表单设计 | 配置新增/编辑数据时展示的字段与控件 |
| 列表设计 | 配置数据列表展示哪些列、哪些可查询 |
| 动态页面 | 根据模型配置自动生成的业务功能页面 |
| 自定义页面 | 通过拖拽组件自由组合布局、数据与交互的独立页面 |
