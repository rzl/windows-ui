# 消息中心与待办中心

## 功能概述

低代码管理平台顶部提供统一的通知入口（铃铛图标），集中展示：

- **待办**：来自流程引擎的审批待办任务。
- **消息**：系统通知、流程结果通知等未读消息。
- **已读**：最近查看过的消息记录。

通过 WebSocket 实时推送，用户无需刷新页面即可收到新的待办提醒。

## 使用入口

登录后，在页面右上角用户头像左侧可看到铃铛图标：

- 红色角标表示当前未读消息与待办任务总数。
- 点击铃铛展开下拉面板，默认显示「待办」Tab。
- 切换 Tab 可查看消息与已读记录。

## 待办处理

1. 点击顶部铃铛 → 选择「待办」Tab。
2. 点击任意待办项，跳转至「我的待办」页面。
3. 在「我的待办」页面点击「详情」查看业务数据与流程轨迹。
4. 点击「通过」或「驳回」，填写审批意见后提交。
5. 处理完成后，对应待办消息自动标为已读，顶部角标自动减少。

## 消息阅读

1. 点击顶部铃铛 → 选择「消息」Tab。
2. 未读消息标题前有小红点标识。
3. 点击消息标题，系统会自动：
   - 将该条消息标为已读；
   - 若消息带有跳转链接，则自动跳转到对应页面；
   - 若消息无跳转链接，则弹出消息详情弹窗。
4. 点击「全部已读」可将当前全部未读消息一键已读。

## 消息类型

| 类型 | 说明 |
|------|------|
| 待办 | 流程引擎产生的审批任务提醒 |
| 通知 | 流程审批结果、系统公告等 |
| 系统 | 平台级系统消息 |

## 业务类型

| 类型 | 说明 |
|------|------|
| 流程 | 来自工作流引擎 |
| 低代码 | 来自低代码业务模型（预留） |
| 系统 | 来自平台系统 |

## 消息管理

管理员可通过左侧菜单「监控」→「消息管理」进入消息列表：

- 查看全部消息记录。
- 按消息类型、业务类型筛选。
- 手动发送消息给指定用户。
- 删除历史消息。

## 常见问题

**Q：为什么收到消息后页面没有提示？**
A：请检查浏览器是否允许 WebSocket 连接；若网络断开过久，可刷新页面重新建立连接。

**Q：待办处理完成后角标没有减少？**
A：角标会在处理成功后自动刷新；若未变化，可点击铃铛手动刷新面板数据。
