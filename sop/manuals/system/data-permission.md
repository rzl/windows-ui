# 数据权限与字段权限

## 概述

数据权限用于控制不同角色在同一业务模型中可见的数据范围；字段权限用于控制角色对具体字段的读/写/隐藏权限。

## 数据权限规则

### 进入菜单

系统管理 → 数据权限

### 创建规则

1. 点击「新增」按钮。
2. 填写规则编码、规则名称。
3. 选择关联模型：规则只对选中的数据模型生效。
4. 选择作用范围：
   - **全部数据**：不限制数据范围。
   - **本部门**：只能看到 `dept_id` 与当前用户部门相同的记录。
   - **本部门及子部门**：看到当前用户部门及其所有子部门的记录。
   - **仅本人**：只能看到 `create_by` 与当前用户相同的记录。
   - **指定角色**：对选中角色生效（仅作为角色绑定的候选）。
   - **指定用户**：仅对选中用户生效。
5. 自定义过滤（可选）：输入 JSON 数组，例如 `[{"field":"status","op":"=","value":"1"}]`，支持 `= / != / > / < / >= / <= / like / in`。
6. 保存规则。

### 绑定到角色

1. 进入系统管理 → 角色管理。
2. 编辑目标角色，切换到「数据权限」Tab。
3. 勾选需要绑定的数据权限规则。
4. 保存角色。

> 一个角色可绑定多条规则，同一模型下的多条规则之间取并集（OR）。

## 字段权限规则

### 进入菜单

系统管理 → 字段权限

### 创建规则

1. 点击「新增」按钮。
2. 选择关联模型和字段。
3. 选择权限类型：
   - **可读可写**：正常显示和编辑。
   - **只读**：表单中显示但不可编辑。
   - **隐藏**：列表不显示该列，表单不显示该字段。
4. 指定角色（可选）：不勾选则对所有角色生效。
5. 保存规则。

## 权限生效说明

- 超级管理员（角色 ID 为 1）不受数据权限和字段权限限制。
- 未配置规则时，默认所有数据可见、所有字段可读可写。
- 数据权限会影响动态 CRUD 列表、详情、编辑、删除、导出。
- 字段权限会影响动态 CRUD 列表列展示、表单字段展示与编辑、导入字段校验。
