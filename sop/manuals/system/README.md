# 系统管理

## 系统公告

用于发布系统通知和公告。

进入「系统管理」→「系统公告」：

- 新增公告：填写标题、类型、内容、排序和状态。
- 公告类型支持「通知」和「公告」。
- 状态为禁用的公告不会在前台展示。

## 字典分类

用于对系统字典进行分组管理。

进入「系统管理」→「字典分类」：

- 新增/编辑分类：填写分类编码、名称、排序和状态。
- 在「字典管理」页面，创建字典时可选择所属分类。
- 字典列表会显示每个字典的分类名称。

## 字典管理

见 `sop/manuals/lowcode/model.md` 中「使用系统字典作为选项」章节。

## 职务管理

用于维护组织内的职务信息。

进入「系统管理」→「职务管理」：

- 新增/编辑职务：填写职务编码、名称、排序和状态。
- 职务可用于后续用户管理中的职务字段关联（待扩展）。
