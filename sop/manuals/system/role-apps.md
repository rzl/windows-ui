# 角色应用授权

## 功能简介

通过角色应用授权，管理员可以控制每个角色能够看到哪些应用。被授权的应用会自动出现在该角色用户的侧边栏菜单和应用市场中。

## 使用前提

- 已存在需要授权的应用（在「在线开发」→「应用管理」中创建并发布）。
- 当前用户具有 `role:edit` 或 `role:create` 权限。

## 操作步骤

### 为角色分配应用

1. 登录低代码平台。
2. 在左侧菜单选择「系统管理」→「角色管理」。
3. 点击目标角色的「编辑」按钮。
4. 在弹窗中切换到「应用授权」Tab。
5. 勾选需要授权给该角色的应用。
6. 点击「确定」保存。

### 取消授权

1. 打开角色编辑弹窗。
2. 切换到「应用授权」Tab。
3. 取消勾选对应应用。
4. 点击「确定」保存。

## 权限说明

- 超级管理员（`admin`）拥有 `*` 权限，默认可以看到全部应用，无需单独授权。
- 普通角色必须被明确授权某个应用后，才能看到该应用对应的菜单和应用市场入口。
- 应用内部的具体资源（如某个数据模型页面）仍受原有菜单权限控制。

## 常见问题

**Q：给角色授权了应用，但用户还是看不到？**

A：请检查：
1. 应用是否已发布并上架到应用市场；
2. 用户是否已经被分配到该角色；
3. 用户是否重新登录（权限在登录时加载）。

**Q：应用授权和菜单权限有什么关系？**

A：应用授权控制「能否看到应用」；菜单权限控制「能否看到系统菜单项」。两者相互配合，建议为普通角色同时授予必要的菜单权限和应用权限。
