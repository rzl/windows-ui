# 菜单管理

## 功能说明

菜单管理用于维护系统左侧导航菜单。菜单支持多级结构（系统内置菜单为最多三级：一级功能中心 → 二级职能分组 → 三级页面），每个菜单可关联一个权限码。

内置菜单的三级结构约定：

| 层级 | 说明 | 示例 |
|------|------|------|
| 一级 | 功能中心（目录或直接可点页面） | 系统管理、仪表盘 |
| 二级 | 内容较多的中心下的职能分组 | 组织管理、数据建模、我的流程 |
| 三级 | 具体功能页面 | 用户管理、数据模型 |

分组节点只需填写上级菜单、标题与路径（如 `/system/org`），无需组件路径与权限码；页面叶子节点需填写组件路径与权限码。

## 新增菜单

1. 进入「系统管理」→「权限管理」→「菜单管理」。
2. 点击「+ 新增」按钮。
3. 选择上级菜单，根菜单选择「根菜单」。
4. 填写菜单标题、路由名称、路由路径、组件路径。
5. 填写权限码（用于按钮级权限控制）。
6. 设置排序和状态。
7. 点击「确定」保存。

## 菜单字段说明

| 字段 | 说明 |
|------|------|
| 上级菜单 | 该菜单归属于哪个父菜单 |
| 菜单标题 | 左侧菜单显示的文字 |
| 路由名称 | Vue 路由名称，建议英文 |
| 路由路径 | 页面访问地址，例如 `/system/user` |
| 组件路径 | 前端组件相对路径，例如 `views/system/UserList.vue` |
| 权限码 | 控制哪些角色可以看到该菜单 |

## 删除菜单

删除菜单后，拥有该菜单权限的用户将不再能看到此菜单。
