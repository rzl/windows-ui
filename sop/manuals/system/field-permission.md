# 字段权限

## 功能概述

字段权限用于控制不同角色在数据模型中能看到、能编辑哪些字段。管理员可以为敏感字段（如薪资、身份证号、联系方式等）设置隐藏、只读或可编辑权限，绑定到角色后自动生效。

## 使用入口

进入「系统管理」→「字段权限」菜单，可查看已配置的字段权限规则列表。

## 创建字段权限规则

1. 点击「+ 新增规则」。
2. 填写表单：
   - **关联模型**：选择要控制的数据模型。
   - **受控字段**：选择模型下的字段。
   - **可读**：勾选后该字段可见。
   - **可编辑**：勾选后该字段可编辑；不勾选则只读。
   - **隐藏**：勾选后该字段完全不可见（优先级高于可读）。
   - **生效角色**：选择规则对哪些角色生效；为空则对所有角色生效。
3. 点击「保存」。

## 权限优先级

| 状态 | 列表表现 | 表单表现 |
|------|----------|----------|
| 隐藏 | 不显示该列 | 不显示该字段 |
| 只读 | 正常显示 | 显示但不可编辑 |
| 可编辑 | 正常显示 | 正常编辑 |

> **注意**：超级管理员（roleId = 1 或拥有 `*` 权限）不受字段权限限制。

## 生效范围

字段权限在以下场景自动生效：

- 低代码动态 CRUD 列表（不显示隐藏字段）
- 低代码动态表单（隐藏或禁用无权限字段）
- 动态 CRUD 新增/更新接口（禁止写入无编辑权限的字段）
- 自定义页面/报表/仪表盘中的数据模型数据源

## 常见问题

**Q：为什么字段权限没有生效？**
A：请检查：
1. 规则是否已启用；
2. 生效角色是否包含当前登录用户的角色；
3. 当前用户是否为超级管理员（超级管理员不受限制）；
4. 字段编码是否与模型字段一致。

**Q：多个规则同时作用于一个字段时如何生效？**
A：系统按规则 ID 倒序取最新一条生效规则。
