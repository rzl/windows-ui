# 用户管理

## 功能说明

用户管理用于维护系统的登录账号，包括新增、编辑、删除用户以及分配部门和角色。

## 新增用户

1. 进入「系统管理」→「用户管理」。
2. 点击「+ 新增」按钮。
3. 填写用户名、密码、昵称、邮箱、手机号等信息。
4. 选择部门和角色。
5. 设置账号状态为「启用」。
6. 点击「确定」保存。

## 编辑用户

1. 在用户列表中找到需要编辑的用户。
2. 点击「编辑」按钮。
3. 修改相关信息。
4. 点击「确定」保存。

> 编辑时如不修改密码，可留空。

## 删除用户

1. 在用户列表中勾选需要删除的用户。
2. 点击「批量删除」按钮，或单行点击「删除」。
3. 在确认弹窗中点击「确定」。

## 禁用/启用账号

1. 编辑用户。
2. 将状态切换为「禁用」或「启用」。
3. 点击「确定」保存。
