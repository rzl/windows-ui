# 数据模型

## 功能说明

数据模型是低代码开发的基础，每个模型对应数据库中的一张表。通过配置模型和字段，可以快速生成业务功能。

## 创建模型

1. 进入「在线开发」→「数据模型」。
2. 点击「+ 新增模型」按钮。
3. 输入模型编码（英文，例如 `customer`）。
4. 输入模型名称（中文，例如「客户」）。
5. 表名可留空，系统会自动生成 `lc_编码`。
6. 点击「确定」保存。

> 保存后系统会自动在数据库中创建对应的物理表。

## 模型管理

模型列表中提供以下操作：

- **设计**：进入模型设计器，配置字段、表单、列表
- **运行**：打开自动生成的业务页面
- **流程**：为模型绑定审批流程
- **编辑**：修改模型名称、描述和数据权限
- **删除**：删除模型及其物理表

## 数据权限

编辑模型时可以配置数据权限，控制不同用户能看到的数据范围。

| 权限类型 | 说明 |
|----------|------|
| 全部可见 | 所有用户都能看到全部数据 |
| 仅本人 | 只能看到创建人是自己的数据 |
| 本部门 | 只能看到创建人同部门的数据 |
| 本部门及子部门 | 只能看到创建人所在部门及其子部门的数据 |

配置后，系统会在新增记录时自动记录创建人（`create_by`）和部门（`dept_id`），并在列表查询时按权限过滤。

## 字段管理

进入模型「设计」→「字段管理」标签页，可以新增、编辑、删除字段。

### 字段属性

| 属性 | 说明 |
|------|------|
| 字段名 | 英文字段名，对应数据库列名 |
| 显示名称 | 表单和列表中显示的中文名称 |
| 字段类型 | 字符串、文本、数字、布尔、日期、日期时间、下拉选择、单选 |
| 长度 | 字符串类型字段的最大长度 |
| 必填 | 是否必填 |
| 默认值 | 新增记录时的默认值 |
| 关联字典 | 仅「下拉选择」和「单选」类型可用。选择后，选项会从系统字典自动读取 |
| 选项（JSON） | 不关联字典时，可手动填写固定选项 |
| 排序 | 字段显示顺序 |
| 状态 | 启用/禁用 |

### 使用系统字典作为选项

1. 先到「系统管理」→「字典」中创建字典和字典项。
2. 进入模型「字段管理」，新增或编辑一个「下拉选择」或「单选」字段。
3. 在「关联字典」中选择对应字典。
4. 保存字段。

保存后，表单和列表中该字段会自动使用字典中的启用项作为选项，无需再手动填写 JSON。

## 删除模型

删除模型会同时删除对应的物理表和所有数据，请谨慎操作。
