# 首页配置

首页配置用于自定义低代码平台登录后的首页展示内容，支持统计卡片、快捷链接、仪表盘和公告四种组件。

## 进入配置页面

1. 登录低代码平台。
2. 在左侧菜单选择「系统管理」→「首页配置」。
3. 页面会加载当前默认首页配置，若未配置过则显示系统默认布局。

## 组件类型

### 统计卡片

用于展示关键业务指标，例如用户数量、订单数量、待办任务等。

配置项：

- **标题**：卡片上显示的标题。
- **统计字段**：指标标识，用于后端统计项匹配。可选择系统默认字段（用户数量 / 数据模型 / 消息数量），也可自定义字段名。
- **数据源类型**：
  - **无**：使用后端默认统计值。
  - **静态值**：直接填写固定数值。
  - **SQL**：编写 `SELECT` 查询，系统取结果第一条数据的第一个数字字段作为统计值。
  - **内部接口**：调用平台内部接口，取返回 `data` 字段作为统计值。
  - **脚本**：编写 JavaScript 脚本，可调用 `db.raw('SELECT ...')` 执行查询或 `http({ url, method, params, body })` 调用接口。
- **图标 / 颜色**：卡片的视觉样式。

SQL 示例：

```sql
SELECT count(*) AS count FROM lowcode_models WHERE status = 1
```

脚本示例：

```js
const rows = await db.raw("SELECT count(*) AS count FROM users WHERE status = 1")
return rows[0].count
```

### 快捷链接

用于放置常用页面入口。

- **链接路径**：点击后跳转的路由，例如 `/lowcode/model-list`。
- **图标 / 颜色**：按钮样式。

### 仪表盘

用于在首页嵌入已设计好的 ECharts 仪表盘。

- **仪表盘编码**：填写已创建的仪表盘编码。首页加载时会自动执行仪表盘绑定的数据源并渲染图表。

### 公告

用于展示系统通知或说明文字。

- **内容**：公告正文。

## 保存与生效

1. 添加或编辑组件后，点击右上角「保存配置」。
2. 返回首页即可看到最新布局。

## 注意事项

- SQL 数据源仅允许 `SELECT` 查询，禁止包含 `INSERT`、`UPDATE`、`DELETE` 等关键字。
- 自定义统计字段名应唯一，避免多个卡片使用相同字段导致后一个覆盖前一个。
- 仪表盘组件在首页以 iframe 方式嵌入，请确保仪表盘编码正确且已启用。
