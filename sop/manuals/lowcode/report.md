# 报表设计器

## 功能说明

报表设计器用于基于低代码数据模型创建自定义报表。与业务列表不同，报表支持分组汇总、固定过滤条件和运行时参数，适合数据统计与分析场景。

## 进入管理页面

进入「报表中心」→「报表管理」。

## 创建报表

1. 点击「+ 新增报表」。
2. 填写报表编码（英文）、报表名称。
3. 选择数据模型。
4. 点击「确定」保存。
5. 在报表列表中点击「设计」进入报表设计器。

## 设计报表

### 报表列

在「报表列」标签页中：

1. 勾选需要展示的字段。
2. 为每个字段设置报表标签。
3. 如需汇总统计，选择聚合函数：
   - 无：直接展示字段值
   - 求和：对数值字段求和
   - 平均：计算平均值
   - 计数：统计记录数
   - 最大/最小：取最大值/最小值
4. 选择格式化方式（日期、金额、百分比等）。

### 分组

在「分组」标签页中：

1. 选择一个或多个分组字段。
2. 报表列中设置了聚合函数的字段会自动按分组汇总。
3. 未设置聚合函数的字段需要同时作为分组字段，否则查询会报错。

### 过滤条件

在「过滤条件」标签页中：

1. 点击「+ 新增条件」。
2. 选择字段、操作符和值。
3. 保存后，运行报表时会自动应用这些固定条件。

支持的操作符：等于、不等于、大于、大于等于、小于、小于等于、包含、范围。

### 报表参数

在「报表参数」标签页中：

1. 点击「+ 新增参数」。
2. 设置参数名（英文）、显示名、类型、默认值。
3. 运行报表时，页面会显示参数输入框。

> 当前版本参数需要配合过滤条件使用：在过滤条件中填写 `${param.参数名}` 作为值，系统运行时会替换为实际参数值。

## 运行报表

1. 在报表列表中点击「运行」。
2. 如有参数，先填写参数值。
3. 点击「查询」，下方表格会展示报表结果。
4. 点击「导出 Excel」可下载报表。

## 删除报表

在报表列表中点击「删除」，删除后相关配置不可恢复。

## 注意事项

- 一个报表只能关联一个数据模型。
- 报表数据受模型数据权限控制，普通用户只能看到权限范围内的数据。
- 分组汇总时使用聚合函数的字段不能同时作为普通展示列。
