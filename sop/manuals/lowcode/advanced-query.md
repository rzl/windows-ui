# 高级查询面板

在低代码平台的「数据列表页」中，可通过高级查询面板组合多个查询条件，并保存为常用查询，方便后续快速调用。

## 打开查询面板

进入任意数据模型的运行页，列表上方会显示「高级查询」面板。点击「+ 添加条件」或「+ 添加分组」开始配置。

## 配置查询条件

### 单行条件

每条条件包含三个部分：

1. **字段**：选择模型中已启用搜索的字段。
2. **运算符**：根据字段类型自动列出可用运算符。
3. **值**：根据运算符输入一个或多个值。

可用运算符说明：

| 运算符 | 含义 | 适用字段类型 |
|--------|------|--------------|
| 等于 | 字段值与输入值完全相等 | 全部 |
| 不等于 | 字段值与输入值不相等 | 全部 |
| 包含 | 字段值包含输入文本 | 字符串、文本 |
| 不包含 | 字段值不包含输入文本 | 字符串、文本 |
| 开头是 | 字段值以输入文本开头 | 字符串、文本 |
| 结尾是 | 字段值以输入文本结尾 | 字符串、文本 |
| 在列表中 | 字段值在逗号分隔的列表中 | 全部 |
| 不在列表中 | 字段值不在逗号分隔的列表中 | 全部 |
| 范围 | 字段值在两个值之间 | 数字、日期 |
| 大于 / 大于等于 | 字段值大于输入值 | 数字、日期 |
| 小于 / 小于等于 | 字段值小于输入值 | 数字、日期 |
| 为空 | 字段值为 NULL | 全部 |
| 不为空 | 字段值不为 NULL | 全部 |

> 范围条件需要填写「起始值 ~ 结束值」两个输入框。
> 「在列表中 / 不在列表中」可在输入框中用英文逗号分隔多个值。

### 条件分组

当需要表达「A 且（B 或 C）」这类复杂逻辑时，可点击「+ 添加分组」创建条件组。每个分组顶部可切换「且 / 或」：

- **且**：分组内所有条件必须同时满足。
- **或**：分组内任意一个条件满足即可。

分组支持嵌套，最多建议嵌套 3 层，避免查询过于复杂。

## 执行查询

配置完成后点击「查询」按钮，列表会立即刷新。点击「重置」可清空所有条件并恢复全部数据。

## 常用查询

### 保存查询

1. 配置好查询条件后，点击「保存查询」。
2. 在弹窗中输入查询名称。
3. 勾选「设为默认」则进入该模型页面时会自动应用此查询。
4. 点击「确定」保存。

> 若使用已存在的名称保存，会提示是否覆盖。

### 加载查询

在「常用查询」下拉框中选择已保存的查询名称，面板会自动恢复对应条件并执行查询。

### 设为默认

选择常用查询后，点击「设为默认」按钮。下次进入该模型页面时会自动加载默认查询。每个模型只能有一个默认查询。

### 删除查询

选择常用查询后，点击「删除」按钮即可删除。删除后当前查询条件不会被清空，可继续手动查询。

## 注意事项

- 常用查询按用户隔离，只能看到自己保存的查询。
- 管理员无法直接查看或修改其他用户的常用查询。
- 若字段后续被删除或类型变更，已保存的查询可能无法正确生效，请重新保存。
