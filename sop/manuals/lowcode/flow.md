# 流程管理

## 功能说明

流程管理用于为低代码数据模型绑定简单的审批流程。当模型启用流程后，新增记录会自动进入审批流程，审批中的记录不能编辑或删除。

## 流程定义

### 为模型绑定流程

1. 进入「在线开发」→「数据模型」。
2. 在目标模型行点击「流程」。
3. 填写流程编码、名称。
4. 在流程设计器中拖拽节点、连接连线，配置审批人与流转条件。
5. 点击「确定」保存。

### 节点类型

| 类型 | 说明 |
|------|------|
| 开始 | 每个流程必须有且仅有一个开始节点 |
| 审批 | 单人审批节点，需配置审批方式（角色/用户/部门）和审批对象 |
| 会签 | 多人审批节点，支持全部通过或一人通过 |
| 抄送 | 自动通知相关人员，无需审批 |
| 条件 | 根据业务数据表达式自动判断流转方向 |
| 结束 | 流程结束节点 |

### 审批人配置

审批节点支持三种指派方式：

- **角色**：按角色指派，审批对象填写角色 ID。
- **用户**：按用户指派，审批对象填写用户 ID。
- **部门**：按部门指派，审批对象填写部门 ID。

### 会签节点

会签节点用于需要多人审批的场景。

| 属性 | 说明 |
|------|------|
| 会签规则 | 全部通过：所有审批人都通过才流转；一人通过：任一审批人通过即流转 |
| 审批人 | 可配置多个审批人，每项包含类型（角色/用户/部门）和对象 ID |

### 流转条件

| 条件 | 说明 |
|------|------|
| 提交 | 从开始节点提交到第一个审批节点 |
| 通过 | 审批节点通过后流转 |
| 驳回 | 审批节点驳回后流转 |
| 表达式 | 根据业务表单字段值判断，如 `form.amount > 1000` |

### 条件分支

除了固定流转条件外，还可以写成 JavaScript 表达式，根据业务数据走不同分支。

表达式中可通过 `form` 访问业务表单字段。例如：

- `form.amount > 1000`：金额大于 1000 时成立
- `form.type === 'urgent'`：类型为紧急时成立

> 条件表达式仅支持简单比较和逻辑运算。请勿写入复杂或危险代码。

## 我的待办

1. 进入「流程管理」→「我的待办」。
2. 页面会列出当前用户角色/账号需要处理的审批任务。
3. 点击「通过」或「驳回」，可填写审批意见。
4. 通过后流程进入结束节点；驳回后流程状态变为「已驳回」。

## 运行业务页面

当模型启用流程后：

- 新增记录保存后会自动启动流程实例。
- 列表中会显示记录的流程状态：审批中 / 已通过 / 已驳回。
- 审批中的记录不能编辑或删除。
- 已驳回的记录可以重新编辑。

## 注意事项

- 一个模型只能绑定一个启用状态的流程。
- 流程驳回后实例状态会变为「已驳回」，对应业务记录可重新编辑并再次提交。
- 当前版本支持审批、会签、抄送、条件分支；暂不支持子流程、委托、转办等高级特性。
