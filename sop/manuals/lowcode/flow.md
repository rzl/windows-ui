# 流程管理

## 功能说明

流程管理用于为低代码数据模型绑定简单的审批流程。当模型启用流程后，新增记录会自动进入审批流程，审批中的记录不能编辑或删除。

## 流程定义

### 为模型绑定流程

1. 进入「在线开发」→「数据模型」。
2. 在目标模型行点击「流程」。
3. 填写流程编码、名称。
4. 配置节点和流转（JSON 格式）。
5. 点击「确定」保存。

### 节点类型

| 类型 | 说明 |
|------|------|
| start | 开始节点，每个流程必须有且仅有一个 |
| approve | 审批节点，需配置 `assigneeType` 和 `assigneeValue` |
| end | 结束节点 |

### 审批人配置

审批节点支持两种指派方式：

- **role**：按角色指派，`assigneeValue` 填写角色 ID。
- **user**：按用户指派，`assigneeValue` 填写用户 ID。

### 流转条件

| 条件 | 说明 |
|------|------|
| submit | 从开始节点提交到第一个审批节点 |
| approve | 审批节点通过后流转 |
| reject | 审批节点驳回后流转 |

### 示例配置

```json
{
  "nodes": [
    { "id": "start", "type": "start", "name": "开始" },
    { "id": "approve", "type": "approve", "name": "经理审批", "assigneeType": "role", "assigneeValue": "2" },
    { "id": "end", "type": "end", "name": "结束" }
  ],
  "transitions": [
    { "from": "start", "to": "approve", "condition": "submit" },
    { "from": "approve", "to": "end", "condition": "approve" },
    { "from": "approve", "to": "start", "condition": "reject" }
  ]
}
```

## 我的待办

1. 进入「流程管理」→「我的待办」。
2. 页面会列出当前用户角色/账号需要处理的审批任务。
3. 点击「通过」或「驳回」，可填写审批意见。
4. 通过后流程进入结束节点；驳回后流程状态变为「已驳回」。

## 运行业务页面

当模型启用流程后：

- 新增记录保存后会自动启动流程实例。
- 列表中会显示记录的流程状态：审批中 / 已通过 / 已驳回。
- 审批中的记录不能编辑或删除。
- 已驳回的记录可以重新编辑。

## 注意事项

- 一个模型只能绑定一个启用状态的流程。
- 流程驳回后如果流转到开始节点，实例状态会变为 `rejected`。
- 当前版本为简化版流程引擎，暂不支持会签、条件分支、子流程等高级特性。
