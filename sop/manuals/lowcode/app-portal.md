# 低代码平台 · 应用门户使用手册

## 概述

应用门户（工作台）是应用运行页的一种展示模式。与传统的"资源列表"相比，门户模式允许应用设计者自由组合统计卡片、快捷链接、仪表盘、公告、流程待办、资源快捷入口等组件，为业务用户打造更接近业务场景的入口页面。

## 视图模式

每个应用支持两种视图模式：

| 模式 | 说明 |
|------|------|
| 资源列表 | 默认模式，以网格卡片形式展示应用下的模型、报表、仪表盘、流程等资源 |
| 工作台门户 | 以组件化 dashboard 形式展示应用概览、统计、待办、快捷入口等 |

## 配置应用门户

1. 进入左侧菜单 **低代码 → 应用管理**。
2. 找到目标应用，点击 **"设计"**。
3. 切换到 **"门户配置"** 标签页。
4. 选择 **视图模式**：工作台门户。
5. 配置是否在工作台中显示 **应用资源快捷入口**。
6. 点击 **"+ 添加组件"**，按需添加 widget。
7. 填写每个 widget 的标题、图标、颜色及类型专属配置。
8. 点击顶部 **"保存"** 按钮。

## Widget 类型

### 统计卡片

展示一个带图标的统计数字。

| 配置项 | 说明 |
|--------|------|
| 统计字段 | 组件内部字段名，用于接收后端返回的统计值 |
| 数据源类型 | 无 / 静态值 / SQL / 内部接口 / 脚本 |
| 静态值 | 直接填写固定数字 |
| SQL | 仅支持 `SELECT` 查询，返回单行数字或单列数组 |
| 内部接口 | 填写相对路径，如 `/lowcode/customer/count` |
| 脚本 | 使用 `db.raw()` 等执行查询并返回值 |

示例 SQL：

```sql
SELECT COUNT(*) AS value FROM lc_customer
```

### 快捷链接

展示一个跳转按钮。

| 配置项 | 说明 |
|--------|------|
| 链接路径 | 点击后跳转的路由，如 `/lowcode/run/customer` |

### 仪表盘

在工作台中内嵌一个已创建的仪表盘图表。

| 配置项 | 说明 |
|--------|------|
| 仪表盘编码 | 已创建仪表盘的 `code` |

### 公告

展示一段文本公告。

| 配置项 | 说明 |
|--------|------|
| 公告内容 | 纯文本内容 |

### 流程待办

展示当前登录用户的待办任务列表。

| 配置项 | 说明 |
|--------|------|
| 显示条数 | 最多展示几条，默认 5 |

> 待办会自动过滤当前应用关联的流程（根据应用项中的 flow 资源）。

### 应用资源

以网格形式展示应用下的资源入口。

| 配置项 | 说明 |
|--------|------|
| 显示条数 | 最多展示几个资源入口，默认 8 |

## 使用门户

### 普通用户

1. 通过侧边栏或应用市场进入应用运行页。
2. 若应用已配置为工作台门户，将看到配置好的工作台。
3. 点击统计卡片、快捷链接、资源入口或待办条目即可进入对应功能。

### 管理员预览

在应用运行页顶部，具有 `lowcode:app` 权限的管理员可以看到 **"切换工作台" / "切换列表"** 按钮，用于临时预览另一种模式，不会修改应用配置。

## 最佳实践

- **客户管理应用**：统计卡片展示客户总数、今日跟进；仪表盘展示客户等级分布；快捷入口展示客户、联系人、跟进记录。
- **工单管理应用**：统计卡片展示工单总数、待处理数；流程待办展示待审批工单；仪表盘展示优先级分布。
- **首页门户**：平台级首页继续使用 **系统管理 → 首页配置**，其 widget 类型与应用门户相同，可互相参考。

## 注意事项

1. 切换到工作台门户后，普通用户默认以工作台形式进入应用。
2. 如果 `portalConfig` 为空或 `mode` 为 `list`，应用运行页保持原有资源列表。
3. 仪表盘 widget 使用 iframe 渲染，组件卸载时会自动释放 blob URL，避免内存泄漏。
4. SQL 类型的统计卡片仅支持 `SELECT` 查询，后端已做安全限制。
