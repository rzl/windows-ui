# 自定义接口版本管理

## 功能概述

自定义接口版本管理允许管理员为单个接口创建快照。快照会记录接口当前的脚本、路径、方法、访问权限、安全配置与日志保留策略等配置。当脚本修改后需要还原时，可快速回滚到历史版本。

## 使用入口

### 在接口列表中使用

1. 进入「低代码」→「自定义接口」。
2. 在接口列表中找到目标接口。
3. 点击该行操作列的「版本」按钮。
4. 右侧会弹出「接口版本管理」抽屉。

### 在接口编辑器中使用

1. 进入「低代码」→「自定义接口」，点击接口编码进入编辑器。
2. 在编辑器页面下方展开「版本管理」面板。

## 创建快照

1. 点击「+ 创建快照」。
2. 输入版本号（如 `v1.0.0`）和说明。
3. 点击「确定」。

创建快照后，该版本会被标记为「当前版本」。后续每次创建新快照，旧快照会自动变为「历史版本」。

## 查看快照

在版本列表中点击「查看」按钮，可预览该版本保存的接口配置 JSON，包括脚本内容。

## 回滚版本

1. 在版本列表中找到需要恢复的历史版本。
2. 点击「回滚」。
3. 在二次确认弹窗中点击「确定」。

> **注意**：回滚后接口脚本会立即生效，新的请求将使用回滚后的脚本。

## 删除版本

点击版本列表中的「删除」可移除不需要的历史快照。删除版本不会影响当前接口配置。

## 注意事项

1. **回滚即时生效**：自定义接口执行时读取当前脚本，回滚后新请求立即使用旧脚本。
2. **回滚前建议先创建快照**：避免回滚后无法恢复到当前脚本状态。
3. **仅管理员可操作**：创建快照、回滚、删除版本需要管理员权限。
