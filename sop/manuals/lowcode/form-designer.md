# 表单设计器

## 功能说明

表单设计器用于配置新增/编辑数据时展示的字段和控件。

## 进入表单设计

1. 进入「在线开发」→「数据模型」。
2. 点击目标模型的「设计」按钮。
3. 切换到「表单设计」标签页。

## 配置字段

在表单设计页面，可以为每个字段设置：

| 属性 | 说明 |
|------|------|
| 表单显示 | 是否在该表单中显示 |
| 表单类型 | 输入框、文本域、数字、开关、日期、下拉、单选等 |
| 必填 | 是否必填 |
| 校验规则 | 绑定已维护的后端校验规则（如手机号、邮箱、身份证号），提交时自动校验 |

## 保存配置

配置完成后，点击「保存表单配置」按钮。保存后，在动态页面新增/编辑数据时将按此配置渲染表单。

## 校验规则

若字段需要符合特定格式（如手机号、邮箱、身份证号），可按以下步骤绑定校验规则：

1. 先到「在线开发」→「校验规则」中创建规则（填写正则表达式和提示信息）。
2. 进入模型「表单设计」标签页。
3. 在字段行的「校验规则」列选择对应的规则。
4. 保存表单配置。

保存后，动态页面提交表单时会自动调用该校验规则，校验不通过时会阻止保存并提示错误信息。

## 支持的控件类型

- 输入框：适用于短文本
- 文本域：适用于长文本
- 数字：适用于整数或小数
- 开关：适用于是/否类型的字段
- 日期/日期时间：适用于时间字段
- 下拉/单选：适用于有固定选项的字段（需配合字典或字段选项）
