# 表单设计器

## 功能说明

表单设计器用于配置新增/编辑数据时展示的字段和控件。

## 进入表单设计

1. 进入「在线开发」→「数据模型」。
2. 点击目标模型的「设计」按钮。
3. 切换到「表单设计」标签页。

## 配置字段

在表单设计页面，可以为每个字段设置：

| 属性 | 说明 |
|------|------|
| 表单显示 | 是否在该表单中显示 |
| 表单类型 | 输入框、文本域、数字、开关、日期、下拉、单选等 |
| 必填 | 是否必填 |
| 校验规则 | 绑定已维护的后端校验规则（如手机号、邮箱、身份证号），提交时自动校验 |
| 联动显示 | 配置字段显示条件：选择依赖字段并输入依赖值，当依赖字段满足条件时当前字段才显示 |
| 动态选项 | 配置选项从系统字典、SQL、接口或脚本动态加载，并可设置依赖字段实现级联 |

## 字段联动

通过「联动显示」列可以配置字段的显示条件，常见场景：

- 当「客户类型」选择「企业」时，才显示「统一社会信用代码」
- 当「是否需要发票」选择「是」时，才显示「发票抬头」

配置方式：

1. 在当前字段行的「联动显示」第一列选择依赖字段。
2. 第二列输入依赖值。
3. 保存表单配置。

当前支持条件：依赖字段值等于输入值时显示。依赖字段为空时自动隐藏当前字段。

## 保存配置

配置完成后，点击「保存表单配置」按钮。保存后，在动态页面新增/编辑数据时将按此配置渲染表单。

## 校验规则

若字段需要符合特定格式（如手机号、邮箱、身份证号），可按以下步骤绑定校验规则：

1. 先到「在线开发」→「校验规则」中创建规则（填写正则表达式和提示信息）。
2. 进入模型「表单设计」标签页。
3. 在字段行的「校验规则」列选择对应的规则。
4. 保存表单配置。

保存后，动态页面提交表单时会自动调用该校验规则，校验不通过时会阻止保存并提示错误信息。

## 支持的控件类型

- 输入框：适用于短文本
- 文本域：适用于长文本
- 数字：适用于整数或小数
- 开关：适用于是/否类型的字段
- 日期/日期时间：适用于时间字段
- 下拉/单选：适用于有固定选项的字段（需配合字典或字段选项）
- 文件上传：适用于需要上传文件的字段（保存文件名）
- 级联选择：适用于有层级关系的选项字段
- 富文本：适用于需要格式化内容的字段

## 动态选项

对于下拉、单选、级联等需要选项的控件，除了直接配置静态选项外，还可以通过「动态选项」从以下数据源加载：

| 数据源 | 说明 |
|--------|------|
| 系统字典 | 选择已维护的字典编码，选项自动从字典项加载 |
| SQL | 编写只读 SELECT 查询，结果需包含 `label` 和 `value` 字段 |
| 内部接口 | 调用平台内部接口，取返回 `data` 作为选项 |
| 脚本 | 编写 JavaScript 脚本，可调用 `db.raw()` 和 `http()` |

### 级联场景

如需实现「选择省份后加载城市」的级联效果：

1. 在城市字段的「动态选项」中选择数据源类型（如 SQL）。
2. 在「依赖字段」中选择省份字段。
3. 在 SQL 中通过 `${ctx.province}` 引用省份字段值。
4. 保存表单配置。

示例 SQL：

```sql
SELECT name AS label, code AS value FROM city WHERE province_code = '${ctx.province}'
```

当省份字段值变化时，城市字段的选项会自动重新加载。
