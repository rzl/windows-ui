# 自定义页面设计器

## 功能说明

自定义页面设计器允许用户通过拖拽组件的方式，自由组合布局、数据与交互，生成独立的业务页面。设计好的页面可以作为应用资源被应用引用，并通过应用运行门户访问。

## 适用场景

- 需要同时展示多个数据看板、统计卡片、公告的门户首页。
- 需要嵌入多个模型列表、仪表盘、报表的聚合页面。
- 需要自定义布局与文案的静态或半动态展示页面。

## 使用流程

### 1. 创建页面

1. 进入「在线开发」→「自定义页面」。
2. 点击「+ 新增页面」。
3. 填写页面编码、名称、描述，点击确定。
4. 在页面列表中点击「设计」进入设计器。

### 2. 设计页面

设计器分为三个区域：

- **左侧组件库**：提供布局、展示、数据、交互四类组件。
- **中间画布**：拖拽组件到画布，选中后可在右侧编辑属性。
- **右侧属性面板**：配置组件的 props、样式、数据源与事件。

#### 常用操作

- **添加组件**：从左侧拖拽组件到画布或容器内。
- **选中组件**：点击画布中的组件，右侧显示对应属性。
- **调整顺序**：使用组件工具栏的「上移」「下移」按钮。
- **添加子组件**：容器、卡片、栅格、标签页支持子组件，点击「+ 子组件」即可。
- **删除组件**：点击组件工具栏的「删除」按钮。

### 3. 配置数据源

统计卡片、图表等组件支持动态数据源：

- **静态值**：直接填写固定值或 JSON。
- **SQL 查询**：编写只读 SELECT 语句，可附加转换脚本处理结果。
- **内部接口**：配置请求方法、地址、参数与请求体。
- **在线脚本**：编写 JavaScript，可调用 `db.raw()` 和 `http()`。

### 4. 保存与预览

- 点击「保存」将页面配置持久化到后端。
- 点击「预览」可查看页面实际渲染效果。

### 5. 将页面加入应用

1. 进入「在线开发」→「应用管理」。
2. 打开目标应用的设计器。
3. 在「可添加资源」面板切换到「页面」Tab。
4. 点击需要加入的页面，页面会出现在「已选资源」中。
5. 保存应用并发布版本。

### 6. 运行页面

1. 进入应用运行门户（`/lowcode/app-run/:code`）。
2. 在资源列表中找到页面卡片。
3. 点击卡片即可打开页面运行器（`/lowcode/page-run/:code`）。

发布应用后，系统也会自动在左侧菜单生成页面子菜单，刷新页面后即可看到。

## 组件说明

### 布局组件

| 组件 | 说明 |
|------|------|
| 容器 | 普通块级容器，可设置内边距 |
| 卡片 | 带标题的卡片容器 |
| 栅格 | 按列数自动排列子组件 |
| 标签页 | 通过标签切换显示不同子组件 |

### 展示组件

| 组件 | 说明 |
|------|------|
| 文本 | 普通文本，支持标签与对齐方式 |
| 统计卡片 | 显示标题与数值，支持数据源动态获取 |
| 图表 | 基于 ECharts，支持静态 option 或动态数据源 |
| 公告 | 信息提示条 |

### 数据组件

| 组件 | 说明 |
|------|------|
| 数据模型 | 嵌入指定模型的动态 CRUD 页面 |
| 仪表盘 | 嵌入指定仪表盘 |
| 报表 | 嵌入指定报表 |

### 交互组件

| 组件 | 说明 |
|------|------|
| 按钮 | 可配置点击动作：跳转、刷新 |
| 链接 | 点击后跳转到指定路由 |

## 注意事项

- 页面编码全局唯一，保存后不可修改。
- 嵌入模型/仪表盘/报表时，需确保目标资源已存在且当前用户有访问权限。
- 页面配置以 JSON 形式存储，建议避免保存过大的图片或文本内容。
- 当前设计器支持拖拽添加组件与容器接收子组件，复杂布局建议通过「上移/下移」和容器嵌套实现。
