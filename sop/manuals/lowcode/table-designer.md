# 列表设计器

## 功能说明

列表设计器用于配置数据列表页面展示哪些列、哪些列可作为查询条件。

## 进入列表设计

1. 进入「在线开发」→「数据模型」。
2. 点击目标模型的「设计」按钮。
3. 切换到「列表设计」标签页。

## 配置列

在列表设计页面，可以为每个字段设置：

| 属性 | 说明 |
|------|------|
| 列表显示 | 是否在表格中显示该列 |
| 可查询 | 是否支持按该字段关键词搜索 |
| 可排序 | 是否支持点击表头进行升序/降序排序 |
| 列宽 | 该列在表格中的宽度（可选） |

## 保存配置

配置完成后，点击「保存列表配置」按钮。保存后，运行业务页面时将按此配置渲染表格。

## 默认列表

如果未保存列表配置，系统会默认显示所有字段，并自动识别文本字段作为可查询字段。
