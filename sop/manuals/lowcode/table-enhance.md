# 列表设计器增强

## 功能概述

低代码运行页的数据列表支持运行时个性化调整：

- **列宽记忆**：用户拖拽调整列宽后，刷新页面仍保持调整后的列宽。
- **列排序拖拽**：用户可通过拖拽表头调整列的显示顺序，刷新页面后顺序保持不变。

## 使用方式

### 调整列宽

将鼠标悬停在表头单元格右侧，会出现列宽调整指示线，按住鼠标左右拖动即可调整列宽。松开鼠标后，列宽会自动保存。

### 调整列顺序

按住表头单元格（选择列和固定列除外），拖动到目标列位置后松开，即可完成列顺序调整。调整后顺序会自动保存。

## 数据存储

列宽和列顺序保存在浏览器本地存储（`localStorage`）中，每个数据模型使用独立的存储键：

```
w-table-lowcode-table-<模型编码>
```

不同用户、不同浏览器之间的设置互不干扰。

## 恢复默认

清除浏览器对应站点的本地存储数据后，列表会恢复为设计器中配置的默认列宽与列顺序。

## 注意事项

1. **固定列不参与排序**：`fixed: left` 或 `fixed: right` 的列以及选择列不能通过拖拽排序。
2. **多级表头暂不支持**：当前列排序拖拽仅支持单层表头。
3. **清除本地存储**：若列宽或顺序出现异常，可清除浏览器本地存储后刷新页面恢复默认。
