# 低代码平台 · 应用模板使用手册

## 概述

应用模板是低代码平台内置的示例应用，包含完整的数据模型、字段、表单、列表、流程、报表、仪表盘和打印模板。用户只需点击"安装"，即可快速创建一套可运行的业务应用。

## 查看示例模板

1. 登录低代码平台。
2. 进入左侧菜单 **低代码 → 应用市场**。
3. 切换到 **"示例模板"** 标签页，即可看到当前可用的模板列表。

每个模板卡片展示：

- 模板名称
- 分类
- 版本号
- 简介

## 安装示例模板

### 从应用市场安装

1. 在 **应用市场 → 示例模板** 中找到目标模板。
2. 点击卡片上的 **"安装"** 按钮。
3. 在弹出的对话框中确认或修改：
   - **应用编码**：新创建的应用唯一标识（英文、数字、下划线）。
   - **应用名称**：展示名称。
   - **自动发布**：勾选后自动发布应用菜单并授权当前角色；取消勾选则创建为草稿。
4. 点击 **"安装"**，等待安装完成。
5. 安装成功后会自动跳转到应用运行页（已发布）或应用设计器（未发布）。

### 从应用管理安装

1. 进入左侧菜单 **低代码 → 应用管理**。
2. 点击工具栏 **"从模板创建"** 按钮。
3. 在对话框中选择模板并填写应用信息。
4. 点击 **"安装"** 完成创建。

## 内置模板说明

### 客户管理

- **模板编码**：`customer-management`
- **适用场景**：销售团队管理客户信息、联系人、跟进记录。
- **包含内容**：
  - 数据模型：客户、联系人、跟进记录
  - 字典：客户等级、客户来源、所属行业、跟进方式、客户状态
  - 编码规则：客户编号（C + 年月日 + 4 位序号）
  - 校验规则：手机号、邮箱
  - 流程：客户审批流程
  - 报表：客户来源统计
  - 仪表盘：客户等级分布
  - 打印模板：客户信息打印

### 工单管理

- **模板编码**：`work-order-management`
- **适用场景**：运维团队进行工单提交、处理、确认与统计。
- **包含内容**：
  - 数据模型：工单、处理记录
  - 字典：工单优先级、工单状态
  - 编码规则：工单编号（WO + 年月日 + 4 位序号）
  - 流程：工单处理流程（处理 → 确认）
  - 报表：工单状态统计
  - 仪表盘：工单优先级分布
  - 打印模板：工单详情打印

## 注意事项

1. **编码冲突**：若目标应用编码已存在，系统会自动追加后缀，例如 `customer_1`。
2. **权限要求**：安装模板需要 `lowcode:app` 权限，普通用户通常无法安装。
3. **自动授权**：安装成功后，当前用户的角色会自动获得该应用的访问权限，无需再到角色管理中手动授权。
4. **事务安全**：模板安装过程在数据库事务中执行，若中途失败会自动回滚，不会留下不完整数据。
5. **二次开发**：安装后的应用与普通应用完全一致，可在 **应用管理 → 设计** 中继续修改、扩展。

## 常见问题

### Q：安装模板后为什么侧边栏看不到新应用？

A：请检查安装时是否勾选了"自动发布"。若未勾选，需要进入应用设计器手动发布版本；发布后若仍不可见，请联系管理员在角色管理中为该角色授权此应用。

### Q：能否自定义更多示例模板？

A：可以。在 `packages/server/templates/apps/` 目录下新增 JSON 文件，按照现有模板格式编写即可。重启后端服务后新模板会自动出现在应用市场中。

### Q：模板中的流程审批人能否直接生效？

A：示例模板中的审批节点使用角色占位符（如 `manager`、`operator`）。目标环境中若存在同名角色，可直接按角色分配审批任务；若不存在，仅作为示例展示，需进入流程设计器重新配置审批人。
