# 数据模型关联关系

## 概述

在低代码平台中，数据模型关联关系用于描述不同业务模型之间的引用关系。通过关联关系，您可以在表单中使用下拉选择关联数据、在列表中展示关联字段、在自定义页面中通过 `expand` 查询展开关联对象。

平台支持三种关系类型：

- **多对一（belongsTo）**：当前模型的某个字段存储目标模型的主键，如「订单」关联「客户」。
- **一对多（hasMany）**：目标模型的某个字段存储当前模型的主键，如「客户」拥有多个「订单」。
- **多对多（manyToMany）**：通过中间表建立多对多关系，如「用户」与「角色」。

## 创建关联关系

### 1. 进入关联关系页面

在左侧菜单中选择「在线开发」→「关联关系」，进入关联关系列表页。

### 2. 新增关系

点击「+ 新增关系」按钮，填写以下信息：

| 字段 | 说明 |
|------|------|
| 编码 | 关系唯一编码，如 `order_customer` |
| 名称 | 关系名称，如「订单所属客户」 |
| 关系类型 | 多对一 / 一对多 / 多对多 |
| 源模型 | 当前模型编码 |
| 目标模型 | 被关联模型编码 |
| 源字段 | 源模型中用于关联的字段 |
| 目标字段 | 目标模型中用于关联的字段，默认为 `id` |
| 中间表 | 仅多对多关系需要填写 |
| 状态 | 启用 / 禁用 |

### 3. 保存关系

点击「保存」后，关系即可在模型设计器中使用。

## 在字段中使用关联关系

### 1. 创建关联字段

进入「在线开发」→「数据模型」，点击某个模型进入模型设计器。在「字段管理」Tab 中新增字段：

1. 字段类型选择 `ref`（关联模型）。
2. 选择「关联模型」，如 `customer`。
3. 选择「显示字段」，如 `name`。
4. 在「关联关系」下拉框中选择已创建的关系，如 `order_customer`。
5. 可选：填写「筛选条件(JSON)」，限制下拉选项范围，如 `{"status": 1}`。

### 2. 保存字段

点击「确定」保存字段。平台会自动在物理表中创建对应列。

## 业务页面效果

### 表单中

当用户在「订单」页面新增记录时，「客户」字段会以下拉选择形式展示，支持搜索客户名称。

### 列表中

「订单」列表默认会显示客户名称（通过 `customer_id` 关联 `customer` 表的 `name` 字段）。

### 接口中

在调用动态 CRUD 接口时，可通过 `expand` 参数展开关联对象：

```
GET /api/lowcode/order?expand=customer_id
```

返回示例：

```json
{
  "list": [
    {
      "id": 1,
      "customer_id_display": "ABC 公司",
      "customer_id": {
        "id": 5,
        "name": "ABC 公司"
      }
    }
  ]
}
```

## 注意事项

1. **关系编码唯一**：同一关系编码不能重复。
2. **删除限制**：若关系已被字段引用，需先删除或修改字段后才能删除关系。
3. **数据权限**：关联查询会同时受源模型和目标模型的数据权限控制。
4. **中间表**：多对多关系的中间表需要预先存在，并包含源字段和目标字段。
5. **一层展开**：当前 `expand` 只支持一层关联展开，不支持递归展开。
