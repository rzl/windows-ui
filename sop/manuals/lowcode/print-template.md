# 打印模板设计器使用手册

## 功能说明

打印模板设计器用于配置业务单据/报表的打印样式，支持文本、图片、表格、矩形、二维码等组件，可绑定数据模型字段，运行时根据真实数据生成打印预览并支持导出 PDF。

## 入口

1. 进入【低代码开发】→【打印模板】
2. 点击“新增模板”创建打印模板
3. 创建后点击“设计”进入可视化设计器

## 设计器界面

- **左侧组件栏**：点击组件可在画布中添加
- **中间画布**：A4 纸张区域，可拖拽调整元素位置
- **右侧属性栏**：选中元素后编辑位置、大小、内容、字段绑定、样式

## 支持的组件

| 组件 | 说明 |
|------|------|
| 文本 | 静态文本或绑定字段变量 |
| 图片 | 显示图片 URL |
| 表格 | 绑定子模型/主模型字段循环渲染 |
| 矩形 | 用于画边框/分隔线 |
| 二维码 | 将字段值或静态内容生成二维码区域 |

## 字段绑定

- 文本组件可在“绑定字段”中选择当前模型的字段
- 绑定字段后，预览/打印时会自动替换为数据值
- 不绑定字段时显示“内容”中的静态文本

## 表格组件

- 表格列支持配置标签、字段、列宽
- 数据源选择“主模型”时只渲染当前行
- 未来版本支持关联子模型循环

## 纸张与方向

- 纸张大小支持 A4 / A5 / A3 / Letter
- 方向支持纵向 / 横向

## 打印入口

在数据模型的列表页面，如果存在关联的打印模板，工具栏会出现“打印”下拉按钮。选择模板后可预览并打印/另存为 PDF。

## 注意事项

- 打印模板必须关联数据模型
- 若列表已勾选记录，则只打印选中记录；否则打印全部数据
- PDF 导出由浏览器打印功能完成
