# 数据模型导入导出

## 功能概述

数据模型导入导出用于迁移模型本身的配置（模型基础信息、字段、表单、列表、关联关系），而不是业务数据。导出的文件为 JSON，方便在不同环境之间传递、版本控制或备份。

## 导出模型

### 从模型列表导出

1. 进入「低代码」→「数据模型」。
2. 在模型列表中找到目标模型。
3. 点击该行操作列的「导出」按钮。
4. 浏览器会自动下载 `model_<模型编码>_<时间戳>.json` 文件。

### 从模型设计器导出

1. 进入「低代码」→「数据模型」，点击模型名称进入「模型设计器」。
2. 在「字段管理」Tab 中点击「导出模型」按钮。
3. 浏览器会自动下载当前模型的 JSON 文件。

## 导入模型

1. 进入「低代码」→「数据模型」。
2. 点击列表上方工具栏的「导入模型」按钮。
3. 在弹窗中选择冲突处理策略：
   - **跳过已存在模型**（默认）：若模型编码已存在，则跳过不导入。
   - **覆盖已存在模型**：删除旧模型、字段、表单、列表及物理表，重新创建。
   - **存在时报错**：若模型编码已存在，直接返回错误。
4. 选择要导入的 JSON 文件。
5. 点击「确定」。

## 导入文件格式

JSON 文件示例：

```json
{
  "version": "1.0",
  "exportedAt": "2026-06-25T10:00:00.000Z",
  "model": {
    "code": "customer",
    "name": "客户",
    "table_name": "lc_customer",
    "description": "",
    "data_permission": "all",
    "enable_audit": 0,
    "status": 1
  },
  "fields": [
    {
      "field_name": "name",
      "display_name": "客户名称",
      "type": "string",
      "length": 255,
      "required": 1,
      "sort": 0,
      "status": 1
    }
  ],
  "forms": [
    {
      "name": "默认表单",
      "config": { "fields": [] },
      "status": 1
    }
  ],
  "tables": [
    {
      "name": "默认列表",
      "config": { "fields": [] },
      "status": 1
    }
  ],
  "relations": []
}
```

## 注意事项

1. **表名冲突**：导入时会检查 `table_name` 是否已被其他模型使用，若被占用则导入失败。
2. **关联关系依赖**：导入关系时，若源模型或目标模型不存在，该关系会被跳过。
3. **覆盖风险**：选择「覆盖已存在模型」会删除旧物理表及数据，请谨慎使用。
4. **字典与校验规则**：字段中引用的字典编码、校验规则编码需要在目标环境中已存在，否则运行时可能无法正确显示选项或校验。
5. **导入失败**：导入过程中任意步骤失败都会回滚，不会残留半完成模型。
