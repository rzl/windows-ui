# 运行业务页面

## 功能说明

完成数据模型、字段、表单、列表配置后，即可运行自动生成的业务页面。

## 运行方式

1. 进入「在线开发」→「数据模型」。
2. 在模型列表中找到目标模型。
3. 点击「运行」按钮。
4. 系统将打开对应的动态业务页面。

## 页面功能

运行业务页面后，可以进行：

- **查询**：在查询区域输入关键词，点击「查询」
- **新增**：点击「+ 新增」，填写表单后保存
- **编辑**：在表格行尾点击「编辑」
- **删除**：在表格行尾点击「删除」
- **分页**：使用表格下方的分页控件切换页码

## 数据权限

动态页面继承系统权限控制，只有拥有对应权限的用户才能操作。
