# 运行业务页面

## 功能说明

完成数据模型、字段、表单、列表配置后，即可运行自动生成的业务页面。

## 运行方式

1. 进入「在线开发」→「数据模型」。
2. 在模型列表中找到目标模型。
3. 点击「运行」按钮。
4. 系统将打开对应的动态业务页面。

## 页面功能

运行业务页面后，可以进行：

- **查询**：在查询区域选择字段、操作符和值，可添加多个条件，点击「查询」；点击「重置」清空所有条件
- **新增**：点击「+ 新增」，填写表单后保存
- **编辑**：在表格行尾点击「编辑」
- **删除**：在表格行尾点击「删除」
- **批量删除**：勾选表格左侧复选框，点击「批量删除」
- **排序**：点击已开启「可排序」列的表头，可在升序 / 降序 / 默认之间切换
- **导入**：点击「导入」，选择符合表头的 CSV 文件，系统会批量插入数据
- **导出**：点击「导出」，将当前页数据下载为 CSV 文件
- **分页**：使用表格下方的分页控件切换页码

## 查询配置

若需要在业务页面使用多条件查询，请在「列表设计」中为对应字段打开「可查询」开关。查询时支持以下操作符：

| 操作符 | 说明 |
|--------|------|
| 等于 | 字段值完全匹配 |
| 不等于 | 字段值排除匹配 |
| 包含 | 字段值包含输入内容（模糊匹配） |
| 大于 / 小于 | 适用于数字、日期类型字段 |
| 大于等于 / 小于等于 | 适用于数字、日期类型字段 |

## 导入说明

导入文件需为 CSV 格式，首行为表头，表头使用字段名（英文），后续每行为一条记录。

示例：

```csv
name,age,gender
张三,18,1
李四,20,2
```

注意：

- 导入时会跳过 `id`、`create_time`、`update_time` 等保留字段。
- 数字、布尔类型字段会自动转换。
- 如果字段配置了校验规则，导入数据也会经过校验。

## 数据权限

动态页面继承系统权限控制，只有拥有对应权限的用户才能操作。
