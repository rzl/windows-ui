# 系统监控

## 功能说明

系统监控用于查看服务器运行状态和关键日志，帮助管理员及时发现和排查问题。

## 服务器信息

进入「系统监控」→「服务器监控」，可查看：

- 操作系统类型
- CPU 架构
- 主机名
- Node.js 版本
- 系统运行时长
- 内存使用情况
- CPU 负载

## 在线用户

在服务器监控页面下方，可查看当前在线用户示例列表。

## 操作日志

进入「系统监控」→「操作日志」，可查看用户的操作记录：

- 操作用户
- 操作模块
- 请求方法
- 请求路径
- 执行耗时
- 操作结果
- 操作时间

通过关键词可以搜索用户、模块或操作内容。

## 数据日志

数据日志用于记录业务数据的变更快照，目前为基础 API 预留，后续可支持数据对比。
