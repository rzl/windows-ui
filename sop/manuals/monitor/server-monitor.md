# 系统监控

## 功能说明

系统监控用于查看服务器运行状态和关键日志，帮助管理员及时发现和排查问题。

## 服务器信息

进入「系统监控」→「服务器监控」，可查看：

- 操作系统类型
- CPU 架构
- 主机名
- Node.js 版本
- 系统运行时长
- 内存使用情况
- CPU 负载

## 在线用户

在服务器监控页面下方，可查看当前在线用户示例列表。

## 操作日志

进入「系统监控」→「操作日志」，可查看用户的操作记录：

- 操作用户
- 操作模块
- 请求方法
- 请求路径
- 执行耗时
- 操作结果
- 操作时间

通过关键词可以搜索用户、模块或操作内容。

## 数据日志

数据日志用于记录业务数据的变更快照，目前为基础 API 预留，后续可支持数据对比。

## 性能概览与告警

进入「系统监控」页面可查看最近 24 小时的 API 性能指标：

- API 总请求数
- 慢请求数（>1s）
- 服务端错误数
- 慢 SQL 总数
- P95 / P99 接口耗时
- 未读告警数

页面同时提供：

- API 请求趋势图（按分钟聚合）
- 慢接口 TOP10
- 慢 SQL 列表（支持关键字与耗时过滤）
- 告警规则配置
- 告警记录处理

告警规则触发后，系统会通过 WebSocket 实时推送，并向接收人发送站内消息。

## 数据治理

「系统监控」页面底部提供「数据治理」卡片，可管理以下监控类数据的保留策略：

- `api_metrics`：默认 30 天
- `sql_metrics`：默认 30 天
- `alert_records`：默认 90 天
- `custom_api_logs`：默认 30 天
- `operation_logs`：默认 180 天
- `data_logs`：默认 180 天

支持修改保留天数、启用/禁用自动清理，以及手动触发立即清理。后台每 6 小时自动执行一次过期数据清理。
