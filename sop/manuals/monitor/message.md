# 消息中心

## 功能说明

消息中心用于在系统内发送和接收消息。支持站内信，以及短信、邮件、微信等渠道占位。

## 查看消息

1. 进入「消息中心」→「消息管理」。
2. 列表中展示收到的消息。
3. 未读消息会标记为「未读」。
4. 点击「标为已读」可将消息标记为已读。

## 发送消息

1. 进入「消息中心」→「消息管理」。
2. 点击「+ 发送消息」。
3. 输入接收人 ID、标题、内容。
4. 选择发送渠道。
5. 点击「发送」。

> 若接收人已在线，消息将通过 WebSocket 实时推送。

## 消息模板

进入「消息中心」→「模板管理」，可以维护常用消息模板：

- 新增模板
- 编辑模板内容
- 设置模板渠道（站内信/短信/邮件/微信）

发送消息时可以选择已创建的模板快速填充内容。
