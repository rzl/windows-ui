# 登录与退出

## 登录系统

1. 打开浏览器，输入系统管理员提供的访问地址，例如：
   ```
   http://localhost:5174/
   ```
2. 在登录页面输入用户名和密码。
3. 点击「登录」按钮。

> 默认管理员账号：`admin`，密码：`admin`。首次登录后请及时修改密码。

## 忘记密码

如果忘记密码，请联系系统管理员重置。

## 退出系统

1. 将鼠标移动到页面右上角用户名处。
2. 点击「退出」按钮。
3. 退出后将自动返回登录页面。

## 登录超时与会话过期

系统使用访问令牌（Access Token）与会话保持登录状态。当发生以下情况时，页面会自动跳转回登录页：

- 未登录直接访问系统内部页面
- 长时间未操作导致访问令牌过期
- 访问令牌被后端禁用或失效
- 主动点击「退出」按钮

如果访问令牌过期但刷新令牌仍有效，系统会在后台自动换取新的访问令牌并继续当前操作，无需重新登录。若刷新令牌也过期，则需要重新输入用户名和密码登录。

## 登录失败处理

| 错误提示 | 处理方法 |
|----------|----------|
| 用户名或密码错误 | 确认大小写是否正确，或联系管理员重置密码 |
| 账号已被禁用 | 联系系统管理员启用账号 |
| 网络错误 | 检查网络连接或联系运维人员 |
