# 登录与退出

## 登录系统

1. 打开浏览器，输入系统管理员提供的访问地址，例如：
   ```
   http://localhost:5174/
   ```
2. 在登录页面输入用户名和密码。
3. 点击「登录」按钮。

> 默认管理员账号：`admin`，密码：`admin`。首次登录后请及时修改密码。

## 忘记密码

如果忘记密码，请联系系统管理员重置。

## 退出系统

1. 将鼠标移动到页面右上角用户名处。
2. 点击「退出」按钮。
3. 退出后将自动返回登录页面。

## 登录失败处理

| 错误提示 | 处理方法 |
|----------|----------|
| 用户名或密码错误 | 确认大小写是否正确，或联系管理员重置密码 |
| 账号已被禁用 | 联系系统管理员启用账号 |
| 网络错误 | 检查网络连接或联系运维人员 |
