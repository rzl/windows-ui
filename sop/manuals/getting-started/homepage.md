# 首页与导航

## 首页布局

登录成功后进入首页，页面由三部分组成：

- **顶部区域**：显示当前用户信息、退出按钮
- **左侧菜单**：系统功能导航
- **内容区域**：展示当前页面内容

## 菜单说明

左侧菜单为最多三级的多级菜单，按功能分类组织（分组 → 子分组 → 页面）：

| 一级菜单 | 二级/三级功能 |
|----------|--------------|
| 仪表盘 | 系统概览、快捷入口（直接点击进入） |
| 系统管理 | 组织管理（租户、用户、部门、职务）；权限管理（角色、菜单、数据权限、字段权限）；基础配置（字典分类、字典、系统公告） |
| 在线开发 | 数据建模（数据模型、关联关系、编码规则、校验规则、外部数据源）；应用开发（应用管理、应用市场、自定义页面、自定义接口）；扩展治理（插件市场、打印模板、审计日志） |
| 消息中心 | 消息管理、模板管理 |
| 系统监控 | 服务器监控、定时任务、操作日志 |
| 流程中心 | 我的流程（我的待办、流程委托）；流程管理（流程定义、流程绩效） |
| 报表中心 | 报表管理 |
| 仪表盘配置 | 首页配置、仪表盘管理 |

> 应用发布后，应用入口菜单会出现在侧边栏底部（按角色授权显示）。

## 多标签页

打开多个页面后，页面顶部会出现标签页：

- 点击标签切换页面
- 点击标签上的关闭按钮关闭页面
- 首页标签默认不可关闭

## 系统设置

点击顶部右上角用户头像左侧的 **设置** 图标（齿轮），可打开系统设置抽屉，进行以下个性化配置：

| 设置项 | 说明 |
|--------|------|
| 系统语言 | 切换界面语言，目前支持中文（`zh-CN`）与英文（`en-US`） |
| 组件尺寸 | 调整全局组件大小，可选大 / 默认 / 小 |
| 主色 | 设置主题主色，影响菜单高亮、标签页激活态、标题栏渐变等 |
| 成功色 | 操作成功提示、成功按钮等配色 |
| 警告色 | 警告提示、警告按钮等配色 |
| 危险色 | 删除、错误提示、危险按钮等配色 |
| 启用 VConsole | 开启后页面会从 CDN 加载 VConsole 调试面板，关闭后自动销毁 |

设置修改后点击「保存设置」即时生效，并自动保存到浏览器本地，下次登录时恢复。

> 注意：VConsole 仅用于移动端或需要前端调试的场景，开启后会额外加载外部脚本。

## 修改个人信息

1. 点击右上角用户名。
2. 选择「个人中心」。
3. 查看个人信息。

如需修改信息，请联系系统管理员。
