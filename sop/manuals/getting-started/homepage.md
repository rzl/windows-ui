# 首页与导航

## 首页布局

登录成功后进入首页，页面由三部分组成：

- **顶部区域**：显示当前用户信息、退出按钮
- **左侧菜单**：系统功能导航
- **内容区域**：展示当前页面内容

## 菜单说明

左侧菜单按功能分类：

| 分类 | 包含功能 |
|------|----------|
| 仪表盘 | 系统概览、快捷入口 |
| 系统管理 | 用户、角色、菜单、部门、字典 |
| 在线开发 | 数据模型、编码规则、校验规则 |
| 消息中心 | 消息管理、模板管理 |
| 系统监控 | 服务器监控、操作日志 |

## 多标签页

打开多个页面后，页面顶部会出现标签页：

- 点击标签切换页面
- 点击标签上的关闭按钮关闭页面
- 首页标签默认不可关闭

## 系统设置

点击顶部右上角用户头像左侧的 **设置** 图标（齿轮），可打开系统设置抽屉，进行以下个性化配置：

| 设置项 | 说明 |
|--------|------|
| 系统语言 | 切换界面语言，目前支持中文（`zh-CN`）与英文（`en-US`） |
| 组件尺寸 | 调整全局组件大小，可选大 / 默认 / 小 |
| 主色 | 设置主题主色，影响菜单高亮、标签页激活态、标题栏渐变等 |
| 成功色 | 操作成功提示、成功按钮等配色 |
| 警告色 | 警告提示、警告按钮等配色 |
| 危险色 | 删除、错误提示、危险按钮等配色 |

设置修改后点击「保存设置」即时生效，并自动保存到浏览器本地，下次登录时恢复。

## 修改个人信息

1. 点击右上角用户名。
2. 选择「个人中心」。
3. 查看个人信息。

如需修改信息，请联系系统管理员。
