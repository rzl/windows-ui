# 阶段八：报表设计器 + 数据导入导出增强 + 按钮级权限

## 目标

在低代码平台已有模型/表单/列表/流程能力基础上，补齐业务高频使用的三大能力：
1. **报表设计器**：用户可配置化生成数据报表，支持分组聚合与导出；
2. **数据导入导出增强**：支持字典/关联字段显示值导出、大数据量异步导出；
3. **按钮级权限**：列表页面每个按钮可独立配置权限标识，实现更细粒度的访问控制。

## 功能清单

### 报表设计器
- 报表元数据：编码、名称、关联模型、状态
- 报表列配置：字段、显示标签、聚合函数、格式化
- 分组字段：支持按一个或多个字段分组后聚合
- 固定过滤条件：等于、不等于、大于、小于、包含、范围
- 报表参数：运行时可输入的参数（字符串、数字、日期、下拉）
- 报表运行页面：根据参数查询并展示报表
- 报表导出 Excel

### 数据导入导出增强
- 导出时自动转换字典字段为显示文本
- 导出时自动使用关联模型显示字段
- 导入时支持布尔值多种写法（是/否/1/0/YES/NO/true）
- 导入时日期/日期时间/数字类型自动格式化
- 大数据量导出使用异步任务：创建任务 → 后台生成 → 轮询下载

### 按钮级权限
- 列表设计器中可为每个工具栏按钮配置权限标识
- 列表设计器中可为每个行操作按钮配置权限标识
- 后端动态 CRUD 接口按配置校验按钮权限
- 前端根据用户权限动态显示/隐藏按钮
- 未配置权限标识的按钮默认放行

## 数据表

| 表名 | 说明 |
|------|------|
| lowcode_reports | 报表定义 |
| export_tasks | 异步导出任务 |

## 接口约定

### 报表
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /report/reports | 报表列表 |
| GET | /report/reports/:code | 报表详情 |
| POST | /report/reports | 保存报表 |
| DELETE | /report/reports/:id | 删除报表 |
| POST | /report/reports/:code/execute | 执行报表 |
| POST | /report/reports/:code/export | 导出报表 Excel |

### 异步导出
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /lowcode/:modelCode/export-task | 创建导出任务 |
| GET | /lowcode/:modelCode/export-task/:id | 查询任务状态 |
| GET | /lowcode/:modelCode/export-task/:id/download | 下载导出文件 |

## 验收标准

- 可在报表设计器中配置列、分组、过滤条件并保存；
- 运行报表时可根据参数查询并展示结果；
- 导出 Excel 时字典字段显示为中文标签；
- 超过 1000 条数据导出时自动使用异步任务；
- 为某按钮配置权限标识后，无权限用户看不到该按钮且接口调用返回 403；
- `pnpm build:server` 与 `pnpm build:lowcode` 通过。
