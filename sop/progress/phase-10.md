# 阶段十：应用发布与版本管理 + 数据审计日志

## 目标

在阶段九基础上，补齐低代码平台的交付能力与合规能力：
1. **应用发布与版本管理**：将分散的模型/表单/列表/流程/报表/打印模板/外部数据源打包为可发布的业务应用，支持版本快照、发布、回滚、导出导入；
2. **数据审计日志**：对启用审计的模型自动记录字段级数据变更历史，支持按模型/记录/操作人查询。

## 功能清单

### 应用管理（已实现）
- 应用元数据：编码、名称、描述、分类、图标、状态
- 应用设计器：选择模型、流程、报表、仪表盘、打印模板、外部数据源组成应用
- 应用菜单：根据应用内容自动生成菜单与权限点
- 应用版本：创建快照、发布版本、历史版本回滚
- 应用导出：将应用配置打包为 JSON 文件
- 应用导入：上传 JSON 文件恢复应用配置

### 应用管理（待后续扩展）
- 应用市场：内置示例应用模板（客户管理、工单管理）
- 角色分配应用：为角色分配可见应用

### 数据审计日志（已实现）
- 模型可配置 `enableAudit` 是否启用审计
- 新增 `data_audit_logs` 表记录变更
- 自动记录创建、更新、删除、批量删除、导入操作
- 记录变更前后字段对比（diff）
- 审计日志查询页面：按模型、记录 ID、操作类型、操作人、时间筛选
- 审计日志详情弹窗查看 before / after / diff

## 数据表

| 表名 | 说明 |
|------|------|
| lowcode_apps | 应用定义 |
| lowcode_app_items | 应用包含的模型/报表等项 |
| lowcode_app_versions | 应用版本快照 |
| data_audit_logs | 数据审计日志 |

## 接口约定

### 应用管理

应用管理接口挂载在 `/api/apps` 下。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/apps | 应用列表 |
| GET | /api/apps/:code | 应用详情 |
| POST | /api/apps | 保存应用（新增/更新） |
| DELETE | /api/apps/:id | 删除应用 |
| POST | /api/apps/:id/snapshot | 创建版本快照 |
| POST | /api/apps/:id/publish | 发布版本 |
| POST | /api/apps/:id/rollback | 回滚到版本 |
| GET | /api/apps/:id/export | 导出应用 JSON |
| POST | /api/apps/import | 导入应用 |

### 数据审计

审计日志接口挂载在 `/api/audit-logs` 下。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/audit-logs | 审计日志列表 |
| GET | /api/audit-logs/actions | 操作类型枚举 |
| GET | /api/audit-logs/:id | 审计详情 |
