# 子线：行级数据权限

## 来源阶段

[phase-7（子项）：数据权限与审计字段](../../by-phase/phase-7-data-permission-audit.md)、[phase-16：数据权限与行级隔离](../../by-phase/phase-16.md)

## 目标

不同角色/部门/用户在同一业务应用中只能看到自己有权限的数据行。

## 关键实现

- 模型维度配置：全部/本人/部门/子部门/指定角色/指定用户
- 自定义过滤条件
- 动态 CRUD 查询自动注入行级过滤

## 验收标准

- [x] 普通用户只能看到权限范围内的数据
- [x] 超级管理员可查看全部数据
- [x] 未配置规则时默认放行（向后兼容）
