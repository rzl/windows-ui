# 主功能：权限体系

## 目标

建立覆盖认证、角色、菜单、按钮、数据行、字段的多维度权限体系，满足不同角色的访问控制需求。

## 子线清单

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| RBAC 角色权限 | [phase-1](../../by-phase/phase-1.md) | JWT 认证、用户/角色/菜单权限 | ✅ |
| 按钮级权限 | [phase-8](../../by-phase/phase-8.md) | 列表/表单按钮权限标识与校验 | ✅ |
| 行级数据权限 | [phase-7](../../by-phase/phase-7-data-permission-audit.md)、[phase-16](../../by-phase/phase-16.md) | 全部/本人/部门/角色/用户范围过滤 | ✅ |
| 字段级权限 | [phase-16](../../by-phase/phase-16.md) | 字段可读/可编辑/隐藏控制 | ✅ |
| 角色应用授权 | [phase-11](../../by-phase/phase-11.md) | 为角色分配可见应用 | ✅ |

## 已修复（[phase-36](../../by-phase/phase-36.md)）

- 数据权限 `roles` 分支此前为空操作，现与 `users` 分支语义一致（名单外用户不通过该规则获得数据）
- 元数据（模型/插件）新增进程内缓存，权限规则随模型缓存读取（30 秒 TTL + 变更全量失效）
