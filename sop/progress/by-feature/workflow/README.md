# 主功能：工作流引擎

## 目标

为低代码业务模型提供流程审批能力，支持流程定义、实例启动、任务处理与轨迹查询。

## 子线清单

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 流程定义 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 节点、连线、审批人、会签、条件 | ✅ |
| 流程实例 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 业务数据新增后自动启动流程 | ✅ |
| 任务处理 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 我的待办、审批/驳回、审批意见 | ✅ |

| 工作流高级特性 | [phase-32](../../by-phase/phase-32.md) | 节点超时自动流转、流程催办、流程实例强制终止 | ✅ |

## 已修复（[phase-36](../../by-phase/phase-36.md)）

- 审批全程事务化 + 乐观锁（双人同时审批不再双重推进）
- 会签达成后自动取消同节点剩余任务（新增 `cancelled` 状态）
- 在途实例按 `definition_version` 取定义，不随定义修改/回滚变化
- 通过/驳回/转办校验操作人为审批人本人/被委托人/超管
