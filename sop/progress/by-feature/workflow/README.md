# 主功能：工作流引擎

## 目标

为低代码业务模型提供流程审批能力，支持流程定义、实例启动、任务处理与轨迹查询。

## 子线清单

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 流程定义 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 节点、连线、审批人、会签、条件 | ✅ |
| 流程实例 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 业务数据新增后自动启动流程 | ✅ |
| 任务处理 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 我的待办、审批/驳回、审批意见 | ✅ |
| 流程轨迹 | [phase-7（flow）](../../by-phase/phase-7-flow.md) | 按业务主键查询流程历史 | ✅ |
| 消息联动 | [phase-17](../../by-phase/phase-17.md) | 流程待办自动发送消息提醒 | ✅ |
