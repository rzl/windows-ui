# 子线：应用发布与版本管理

## 来源阶段

[phase-10：应用发布与版本管理 + 数据审计日志](../../by-phase/phase-10.md)

## 目标

支持将分散资源打包为应用，进行版本快照、发布、回滚、导出导入。

## 关键实现

- `lowcode_apps`、`lowcode_app_items`、`lowcode_app_versions` 表
- 应用 CRUD、版本快照、发布、回滚
- 应用 JSON 导出/导入
- 自动根据应用内容生成菜单与权限点

## 验收标准

- [x] 可创建应用并选择多个模型/报表打包
- [x] 应用发布后可自动生成菜单
- [x] 可导出应用 JSON 并导入到新环境
