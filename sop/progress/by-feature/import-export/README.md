# 主功能：数据导入导出

## 目标

为低代码业务数据提供导入导出能力，支持字典/关联字段显示值转换和大数据量异步导出。

## 子线清单

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 导入增强 | [phase-8](../../by-phase/phase-8.md) | 布尔值、日期、数字类型自动格式化 | ✅ |
| 导出增强 | [phase-8](../../by-phase/phase-8.md) | 字典/关联字段显示值导出 | ✅ |
| 异步导出 | [phase-8](../../by-phase/phase-8.md) | 大数据量后台生成、轮询下载 | ✅ |
