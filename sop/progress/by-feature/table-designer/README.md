# 主功能：列表设计器

## 目标

通过可视化配置生成数据列表，支持列配置、查询条件、操作按钮、权限控制。

## 子线清单

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 基础列表设计器 | [phase-3](../../by-phase/phase-3.md) | 展示列、查询条件、操作按钮配置 | ✅ |
| 按钮级权限 | [phase-8](../../by-phase/phase-8.md) | 工具栏/行操作按钮权限标识 | ✅ |
| 字段权限集成 | [phase-16](../../by-phase/phase-16.md) | 隐藏字段不展示列 | ✅ |

| 高级查询面板 | [phase-26](../../by-phase/phase-26.md) | 嵌套 AND/OR 条件组、常用查询保存 | ✅ |
