# 主功能：表单设计器

## 目标

通过可视化配置生成业务表单，支持基础控件、高级布局、字段联动、权限控制与插件扩展。

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 基础表单设计器 | [phase-3](../../by-phase/phase-3.md) | 字段拖拽、基础属性配置、表单预览 | ✅ |
| 字段联动 | [phase-3](../../by-phase/phase-3.md) | dependsOn 动态显示/隐藏字段 | ✅ |
| 表单高级布局 | [phase-9](../../by-phase/phase-9.md) | 分组、标签页、栅格、子表 | ✅ |
