# 主功能：外部数据集成

## 目标

接入 REST API 与外部数据库作为数据源，供字段选项、关联字段、报表、仪表盘使用。

| 子线 | 阶段 | 内容 | 状态 |
|------|------|------|------|
| 外部数据源管理 | [phase-9](../../by-phase/phase-9.md) | REST/数据库数据源配置、测试连接 | ✅ |
| 字段选项集成 | [phase-9](../../by-phase/phase-9.md) | 字段下拉选项可选择外部数据源 | ✅ |
| 报表数据源集成 | [phase-9](../../by-phase/phase-9.md) | 报表支持外部数据源 | ✅ |
