# 系统架构总览

## 总体结构

```
┌─────────────────────────────────────────────────────────────┐
│                     低代码管理平台                             │
├──────────────┬─────────────────┬──────────────────────────────┤
│  前端展示层   │    低代码设计层  │        后端服务层             │
│              │                 │                              │
│ lowcode-admin│  表单/列表设计器  │     packages/server          │
│ (Vue3+Pinia) │  配置化渲染引擎  │  (Express+Knex+SQLite)       │
├──────────────┴─────────────────┴──────────────────────────────┤
│                      UI 组件库                                 │
│              packages/windows-ui (Vue3)                       │
└─────────────────────────────────────────────────────────────┘
```

## 模块划分

### 1. 系统管理
- 用户管理、角色管理、菜单管理、部门管理
- 字典管理、分类字典、系统公告、职务管理、通讯录
- 多数据源管理、白名单管理、第三方配置、多租户管理

### 2. 在线开发（低代码）
- 在线表单：通过 JSON 配置生成业务表单
- 仪表盘设计器：iframe 嵌入 ECharts
- 系统编码规则、系统校验规则

### 3. 消息中心
- 消息管理、模板管理
- 短信、邮件、微信推送接口占位

### 4. 系统监控
- 定时任务、数据源管理、性能扫描监控
- 系统日志、数据日志、SQL 监控、在线用户

### 5. 通用组件
- 高级查询、Monaco 编辑器（iframe）、结果页、异常页、个人页

### 6. 高级功能
- WebSocket 消息通知

## 数据流

1. 用户登录 → `/auth/login` 返回 JWT
2. 前端请求携带 `Authorization: Bearer <token>`
3. JWT 中间件校验身份，权限中间件校验操作权限
4. Controller 处理请求，Service 处理业务，Knex 操作数据库
5. 统一响应格式返回前端

## 部署形态

- 开发：前端 Vite dev server + 后端 Express server 分别启动
- 生产：前端构建为静态资源，后端 Express 提供 API，可由 Nginx 统一代理
