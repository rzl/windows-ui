# 流程可视化设计器

低代码平台提供可视化流程设计器，用于配置审批流程、会签、条件分支、抄送等节点。

## 节点类型

| 类型 | 说明 | 可配置属性 |
|------|------|-----------|
| `start` | 开始节点 | 名称 |
| `approve` | 审批节点 | 名称、审批方式（角色/用户/部门）、审批对象 |
| `cc` | 抄送节点 | 名称、抄送方式、抄送对象 |
| `condition` | 条件节点 | 名称、条件表达式 |
| `sign` | 会签节点 | 名称、会签规则（全部通过/一人通过）、审批人列表 |
| `end` | 结束节点 | 名称 |

## 使用方式

在「流程定义」页面点击新增/编辑，打开流程设计弹窗：

1. 从左侧拖拽节点到画布
2. 鼠标悬停节点底部/顶部连接点，拖拽连线
3. 点击节点/连线，在右侧属性面板编辑
4. 点击「确定」保存

## 条件表达式

条件节点和连线上均可配置表达式。表达式使用 JavaScript 语法，上下文变量为 `form`（表单数据）。

示例：

```js
form.amount > 1000
form.status === 'urgent'
form.days >= 3 && form.dept === 'sales'
```

连线的默认条件选项为：

- `submit`：提交
- `approve`：通过
- `reject`：驳回

## 后端数据结构

设计器保存时会转换为后端兼容的 JSON 结构：

```json
{
  "nodes": [
    { "id": "start", "type": "start", "name": "开始" },
    { "id": "approve", "type": "approve", "name": "经理审批", "assigneeType": "role", "assigneeValue": "manager" },
    { "id": "end", "type": "end", "name": "结束" }
  ],
  "transitions": [
    { "from": "start", "to": "approve", "condition": "submit" },
    { "from": "approve", "to": "end", "condition": "approve" }
  ]
}
```

## 运行时行为

- **审批节点**：生成待办任务，指定审批人/角色/部门处理
- **会签节点**：根据规则生成多个任务，全部通过或一人通过后继续流转
- **抄送节点**：自动记录抄送并立即流转，不阻塞流程
- **条件节点**：根据表单数据自动匹配表达式并流转
