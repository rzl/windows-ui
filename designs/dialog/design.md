# Dialog 对话框 - 设计文档

## 组件分类
Feedback

## 视觉设计

### 设计理念
该组件采用 Windows XP 经典视觉风格，具有以下设计特征：
- 经典的蓝白配色方案
- 凸起/凹陷的 3D 边框效果
- 渐变标题栏
- Tahoma 字体家族

### 色彩规范
- 主色: #245edb (XP Blue)
- 成功色: #3a9e3a
- 警告色: #e4a010
- 危险色: #d92b2b
- 背景色: #ece9d8
- 边框色: #919b9c

### 尺寸规范
- 字体基础大小: 11px
- 圆角: 3px (基础)
- 组件高度: 32px (默认)

## 交互设计
- 悬停状态: 颜色加深/高亮
- 点击状态: 内阴影按压效果
- 禁用状态: 透明度 0.5
- 聚焦状态: 蓝色边框高亮
- 头部拖动: 默认允许通过标题栏拖动对话框位置，鼠标指针变为 move 样式；拖动过程中点击遮罩不关闭对话框；每次打开时位置重置为居中；全屏模式下不可拖动
- 全屏模式: 对话框占满整个视口，内容区域自动撑开，边框保持 XP 3D 风格

## 可访问性
- 支持键盘导航
- 颜色对比度符合 WCAG 2.0 AA 标准
- 支持屏幕阅读器
