# WAdvancedQueryBuilder 设计文档

## 组件分类

数据展示 / 查询筛选

## 视觉设计

### 布局

- 整体容器使用经典 XP 风格边框：上、左白边，下、右灰边，营造凹陷效果。
- 顶部为标题与工具栏，工具栏按钮横向排列。
- 下方为条件组区域，条件组以卡片形式嵌套展示。
- 条件行横向排列：字段选择器 + 运算符选择器 + 值输入区 + 删除按钮。

### 色彩

- 背景：使用 `--w-bg-color`（#ece9d8）。
- 条件组背景：根据嵌套层级使用半透明白色/浅蓝/浅黄交替，便于区分层级。
- 边框：#c0c0c0。
- 主按钮：使用 `--w-color-primary` 渐变。

### 尺寸

- 内边距：容器 12px，条件组 10px。
- 条件行间距：8px。
- 选择器宽度：字段 140px，运算符 120px，逻辑 80px。

## 交互设计

### 添加条件

点击「+ 添加条件」在当前分组末尾插入一条空条件，默认使用第一个字段与推荐运算符。

### 添加分组

点击「+ 添加分组」在当前分组末尾插入一个空的子分组，默认逻辑为「且」。

### 切换逻辑

每个分组顶部提供「且 / 或」切换，实时影响该分组内所有条件的连接方式。

### 删除

- 单行条件：点击行尾「删除」按钮移除。
- 整个分组：点击分组头部「删除分组」按钮移除（根分组不可删除）。

### 字段切换

切换字段时，若当前运算符在新字段类型下不可用，则自动回退为第一个可用运算符。

### 运算符切换

切换运算符时：
- 切换到「范围」：值重置为 `["", ""]`。
- 切换到「为空 / 不为空」：清空值输入。
- 其他情况：保留原有值。

### 查询与重置

- 点击「查询」触发 `search` 事件，输出当前条件树。
- 点击「重置」清空所有条件并触发 `reset` 事件。

## 可访问性

- 选择器与输入框可通过 Tab 键聚焦。
- 按钮使用原生 `<button>` 元素，支持键盘触发。
- 为空/不为空条件不渲染值输入框，避免用户困惑。

## 响应式

- 桌面端：条件行横向排列。
- 移动端（≤768px）：条件行垂直堆叠，每个控件占满宽度。
