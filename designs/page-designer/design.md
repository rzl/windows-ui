# WPageDesigner 设计文档

## 组件分类

- 分类：低代码 / 设计器
- 标签：`WPageDesigner`、`w-page-designer`

## 视觉设计

- 三栏布局：左侧组件库（约 260px）、中间画布（flex:1）、右侧属性面板（280px）。
- 移动端切换为单栏 + 顶部标签切换。
- 画布使用虚线边框与浅色背景，选中节点使用主色实线边框。
- 组件库每行展示两个组件项，使用图标 + 文字的朴素按钮，尺寸跟随全局尺寸。
- 工具栏与节点工具栏统一使用图标按钮，hover 显示 `title` 提示。
- 深色模式下整体跟随 `html.dark` 变量反转背景、边框与文字色。

## 交互设计

- 桌面端：从组件库拖拽组件库项到根画布或容器，拖拽过程中目标区域（根画布 `.canvas-body` 或容器 `.children-area`）会添加高亮样式。
- 节点排序：拖动节点工具栏的排序把手，可在同级列表中重新排序；目标节点上方/下方/容器内部分别显示顶部边框、底部边框、背景高亮提示。
- 大纲联动：左侧大纲展示组件层级，点击大纲节点选中画布节点；选中嵌套节点时自动展开祖先容器；大纲节点也支持拖拽排序。
- 移动端：点击组件库项直接添加到当前选中容器或根画布；支持触屏拖拽。
- 组件库分组可收起展开，顶部搜索实时过滤组件。
- 属性面板：选中节点后展示对应属性表单，统一使用 `WForm` / `WFormItem` 与 Windows UI 基础输入组件；通过 `WForm` 统一注入尺寸与标签宽，所有控件跟随全局尺寸；支持 JSON 文本编辑与数据源、事件子编辑器。
- 预览：弹窗内使用 `WPageRenderer` 实时渲染当前配置。
- 深色模式：工具栏提供一键切换，状态保存在组件内部，同步切换全局 `html.dark` 类。
- 撤销/重做：基于 `usePageHistory` 维护历史栈，支持 Ctrl+Z / Ctrl+Shift+Z。
- 表单数据：表单组件的值统一托管在页面级 `formData` 中，便于整页提交与联动。

## 可访问性

- 组件库项具备 `draggable` 属性与触屏替代操作。
- 按钮与输入框使用 Windows UI 基础组件，保持键盘可访问。
