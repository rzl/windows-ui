# WPageDesigner 设计文档

## 组件分类

- 分类：低代码 / 设计器
- 标签：`WPageDesigner`、`w-page-designer`

## 视觉设计

- 三栏布局：左侧组件库（180px）、中间画布（flex:1）、右侧属性面板（280px）。
- 移动端切换为单栏 + 顶部标签切换。
- 画布使用虚线边框与浅色背景，选中节点使用蓝色实线边框。
- 组件项使用卡片式展示，hover 时背景变深。

## 交互设计

- 桌面端：拖拽组件库项到画布或容器；悬停显示节点工具栏。
- 移动端：点击组件库项直接添加到当前选中容器或根画布；支持触屏拖拽。
- 属性面板：选中节点后展示对应属性表单，支持 JSON 文本编辑；表单组件可配置 `field` 绑定字段。
- 预览：弹窗内使用 `WPageRenderer` 实时渲染当前配置。
- 表单数据：表单组件的值统一托管在页面级 `formData` 中，便于整页提交与联动。

## 可访问性

- 组件库项具备 `draggable` 属性与触屏替代操作。
- 按钮与输入框使用 Windows UI 基础组件，保持键盘可访问。
