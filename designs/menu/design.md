# Menu 菜单 - 设计文档

## 组件分类
Navigation

## 视觉设计

### 设计理念
该组件采用 Windows XP 经典视觉风格，具有以下设计特征：
- 经典的蓝白配色方案
- 凸起/凹陷的 3D 边框效果
- 渐变标题栏
- Tahoma 字体家族

### 色彩规范
- 主色: #245edb (XP Blue)
- 成功色: #3a9e3a
- 警告色: #e4a010
- 危险色: #d92b2b
- 背景色: #ece9d8
- 边框色: #919b9c

### 尺寸规范
- 字体基础大小: 11px
- 圆角: 3px (基础)
- 组件高度: 32px (默认)
- 收起模式宽度: 48px

### 收起模式
- 仅保留图标区域，文字与箭头隐藏
- 无图标项以首字符作为占位，背景使用主色、白色文字
- 子菜单从右侧弹出，宽度最小 140px
- 弹出菜单带阴影与边框，保持 XP 风格

### 多级菜单
- 垂直模式：子菜单以内嵌方式逐级展开，层级通过背景色区分（#f0f0f0 → #e8e8e8 → #e0e0e0 → #d8d8d8）
- 水平模式：一级子菜单向下弹出，二级及以上向右级联弹出
- 收起模式：所有子菜单均向右级联弹出
- 各级弹出菜单使用相同的边框与阴影风格

## 交互设计
- 悬停状态: 颜色加深/高亮
- 点击状态: 内阴影按压效果
- 禁用状态: 透明度 0.5
- 聚焦状态: 蓝色边框高亮
- 收起模式: 悬停含子菜单项时右侧弹出子菜单
- 选中子菜单时: 该子菜单及其所有父级菜单项均高亮，已弹出的子菜单自动关闭

## 可访问性
- 支持键盘导航
- 颜色对比度符合 WCAG 2.0 AA 标准
- 支持屏幕阅读器
