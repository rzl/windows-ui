# Table 表格 - 设计文档

## 组件分类
Data

## 视觉设计

### 设计理念
该组件采用 Windows XP 经典视觉风格，具有以下设计特征：
- 经典的蓝白配色方案
- 凸起/凹陷的 3D 边框效果
- 渐变标题栏
- Tahoma 字体家族

### 色彩规范
- 主色: #245edb (XP Blue)
- 成功色: #3a9e3a
- 警告色: #e4a010
- 危险色: #d92b2b
- 背景色: #ece9d8
- 边框色: #919b9c
- 表头渐变: linear-gradient(180deg, #f8f8f8, #e0e0e0)
- 行 hover 背景: #f0f8ff
- 当前行高亮（单选）: #dcebfc
- 斑马纹奇数行: #faf9f6
- 展开行背景: #f5f5f5

### 尺寸规范
- 尺寸可选：small / default / large
- 默认高度：32px（default），跟随 CSS 变量 `--w-component-size`
- 小尺寸：24px（`--w-component-size-small`）
- 大尺寸：40px（`--w-component-size-large`）
- 组件内部图标（如有）随组件 size 联动

### 行状态色（内置辅助类）
- `.is-warning`：背景 #fff8e1（浅黄，用于警示行）
- `.is-danger`：背景 #ffebee（浅红，用于错误行）
- `.is-success`：背景 #e8f5e9（浅绿，用于成功行）

### 固定列视觉
- 固定列使用 `position: sticky` 实现
- 最左侧最后一个固定列右侧加 `box-shadow: 2px 0 4px rgba(0,0,0,0.08)` 模拟分隔
- 最右侧第一个固定列左侧加 `box-shadow: -2px 0 4px rgba(0,0,0,0.08)` 模拟分隔
- 固定列表头 z-index 高于普通 sticky 表头，确保滚动时始终在最上层

### 展开行视觉
- 展开图标使用 ▶ / ▼，字号 10px，颜色 #666，hover 变主色
- 展开行背景为浅灰 #f5f5f5，与数据行区分
- 展开内容区域 padding: 12px 16px

### 树形表格视觉
- 展开图标位于第一个数据列（非 selection/expand 列）单元格内
- 缩进使用等宽空白占位，默认每级 `16px`，通过 `indent` 属性可调
- 叶子节点保留与展开图标同等宽度的空白占位，保持列内容纵向对齐
- 加载中状态显示 ⏳ 图标，不可点击
- 树形展开图标与展开行图标样式一致（▶ / ▼），但位于不同列位置

### 多级表头视觉
- 分组列（有 children 的列）只显示在表头中，使用相同的表头渐变背景
- 分组列的 `colspan` 横跨所有子列，不设置固定宽度
- 叶子列的 `rowspan` 自动填充剩余表头行数，保持表头底部对齐
- 固定列、列宽拖拽、排序筛选等功能均只作用于叶子列

### 虚拟滚动视觉
- 表格容器设置固定高度，开启 `overflow-y: auto`
- 表头保持 `position: sticky; top: 0`，随容器滚动始终置顶
- 仅可视区域内的行实际渲染，上下使用空占位行维持总高度
- 固定列在虚拟滚动下保持 sticky 效果，与纵向滚动同步

### 横向虚拟滚动视觉
- 中间非固定列仅渲染可视区域内的列，被跳过的列用空 `<td>` 占位保持总宽度
- 左右固定列始终渲染，不参与中间列的裁剪
- 占位列宽度等于被跳过列的宽度总和，确保横向滚动条长度与真实布局一致
- 表头与单元格的列宽样式统一通过 `<col>` 计算，避免内容撑开导致错位

## 交互设计
- 悬停状态: 整行背景变为 #f0f8ff
- 点击状态（单选高亮）: 整行背景变为 #dcebfc，保持 XP 经典蓝色选中感
- 禁用状态: 透明度 0.5
- 聚焦状态: 蓝色边框高亮
- 排序图标: 表头文字右侧，未激活灰色、激活主色
- 筛选面板: 表头下方弹出，XP 风格边框 + 阴影，内含复选框列表与操作按钮
- 多选: 表头全选复选框支持半选（indeterminate）状态
- 展开行: 点击 ▶ 展开为 ▼，展开内容以动画形式呈现（CSS transition）
- 树形展开: 点击父节点前的 ▶ 展开子节点列表，点击 ▼ 收起；懒加载时先显示 ⏳ 等待加载完成后自动展开
- 树形多选联动: 父节点选中时级联选中所有子孙；子节点全部选中时父节点自动选中；子节点部分选中时父节点显示半选

## 可访问性
- 支持键盘导航
- 颜色对比度符合 WCAG 2.0 AA 标准
- 支持屏幕阅读器
