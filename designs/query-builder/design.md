# WQueryBuilder 设计文档

## 组件分类

Others / 管理后台通用组件

## 视觉设计

- 每行一个条件，字段、操作符、值横向排列
- 行尾提供删除按钮
- 底部提供添加条件、查询、重置按钮
- 继承 XP 风格边框与背景

## 交互设计

- 点击"添加条件"新增一行
- 点击"添加分组"新增一个 AND/OR 条件组，支持嵌套
- 点击"删除"移除对应条件或分组
- 点击"查询"抛出当前所有条件（含分组会展开为嵌套结构）
- 点击"重置"清空所有条件与分组
- 支持保存/加载常用查询方案

### 移动端交互

- 屏幕宽度 ≤768px 时，条件行由横向排列切换为垂直堆叠，每个控件占满整行宽度，避免触控时误触相邻元素
- 字段选择、操作符选择、值输入与删除按钮纵向依次排布，保持与桌面端一致的操作顺序
- 底部操作按钮区域允许换行，确保"添加条件"、"查询"、"重置"按钮在小屏幕下仍可完整显示
- 配合弹窗使用时，移动端弹窗自动进入全屏模式，点击全屏切换按钮可退出全屏，退出后恢复拖拽能力

## 可访问性

- 下拉框与输入框有明确的 label/placeholder
- 按钮有清晰的文字说明
