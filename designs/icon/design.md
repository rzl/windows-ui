# Icon 图标 - 设计文档

## 组件分类
Basic

## 视觉设计

### 设计理念
该组件采用 Windows XP 经典视觉风格，具有以下设计特征：
- 经典的蓝白配色方案
- 简洁的线条与扁平化填充
- 16×16 的标准画布尺寸，保持界面一致性
- Tahoma 字体家族

### 色彩规范
- 主色: #245edb (XP Blue)
- 成功色: #3a9e3a
- 警告色: #e4a010
- 危险色: #d92b2b
- 背景色: #ece9d8
- 边框色: #919b9c
- 图标默认色: #000 / #808080

### 尺寸规范
- 基础尺寸: 16×16 px
- 小尺寸: 12×12 px
- 大尺寸: 24×24 px
- 圆角: 3px (基础)
- 组件高度: 32px (默认)

### 图标分组
内置图标按功能分为六大类，便于在文档和示例中分组展示：
1. **方向箭头**：上下左右及折叠箭头
2. **操作交互**：增删改查、上传下载、放大缩小等常用操作
3. **文件系统**：文件夹、文件、图片、视频、音乐、文档
4. **状态提示**：信息、警告、错误、成功、帮助、加载
5. **通用界面**：用户、首页、收藏、日历、邮件等界面元素
6. **后台管理**：电脑、退出、密码、购物车、图表等管理后台专用图标

## 交互设计
- 悬停状态: 颜色加深/高亮
- 点击状态: 内阴影按压效果
- 禁用状态: 透明度 0.5
- 聚焦状态: 蓝色边框高亮

## 可访问性
- 支持键盘导航
- 颜色对比度符合 WCAG 2.0 AA 标准
- 支持屏幕阅读器
