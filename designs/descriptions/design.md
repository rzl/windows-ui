# Descriptions 描述列表 - 设计文档

## 组件分类
Data

## 视觉设计

### 设计理念

该组件用于以键值对形式展示只读信息，采用 Windows XP 经典视觉风格，具有以下设计特征：

- 经典的米色背景（`--w-bg-color`）
- 凸起/凹陷的 3D 边框效果
- 标题使用主色高亮显示
- Tahoma 字体家族
- 表格单元格通过细边框分隔，信息层次清晰

### 色彩规范

- 主色: `#245edb`（标题文字）
- 背景色: `#ece9d8`
- 单元格边框: `#d4d0c8`
- 标签文字: `#666`（次要文字色）
- 值文字: `#000`（主要文字色）

### 尺寸规范

- 组件内边距: `8px`
- 标题字体大小: `var(--w-font-size-medium)`
- 标签字体大小: `var(--w-font-size-small)`
- 值字体大小: `var(--w-font-size-base)`
- 单元格内边距: `6px 8px`
- 默认每行显示 3 列，可通过 `column` 调整

### 布局规则

- 当使用 `items` 属性或 `w-descriptions-item` 子组件时，组件按 `column` 值将描述项等分为若干行
- 每个单元格内上方显示 `label`，下方显示 `value`
- 若数据项总数不能被 `column` 整除，最后一行剩余单元格保持空白占位

## 交互设计

描述列表为只读展示组件，本身不提供交互状态。若值区域需要交互（如复制、链接跳转），由调用方在插槽内容或 `value` 中自行实现。

## 可访问性

- 标签与值在同一单元格内通过视觉层级区分
- 标题使用语义化的 `div` 呈现
- 表格结构使用标准 `table`、`tbody`、`tr`、`td` 标签，便于屏幕阅读器解析
