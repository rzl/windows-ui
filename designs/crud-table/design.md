# WCrudTable 设计文档

## 组件分类

Others / 管理后台通用组件

## 视觉设计

- 查询区域：继承 WSearchForm 的 XP 风格边框与背景
- 工具栏：位于表格上方，按钮横向排列，间距 8px
- 表格：继承 WTable 的条纹、边框、固定列等样式
- 分页：位于表格右下方，继承 WPagination 样式


### 尺寸规范
- 尺寸可选：small / default / large
- 默认高度：32px（default），跟随 CSS 变量 `--w-component-size`
- 小尺寸：24px（`--w-component-size-small`）
- 大尺寸：40px（`--w-component-size-large`）
- 组件内部图标（如有）随组件 size 联动

## 交互设计

- 点击"查询"触发 search 事件
- 点击"重置"清空查询条件并触发 reset 事件
- 分页切换触发 page-change / size-change 事件
- 表格选择变化通过 selection-change 抛出

### 移动端交互

- **触控优先**：在 ≤768px 视口下，所有可点击区域保持足够的触控热区，按钮与表单项间距适当放大，避免误触。
- **全屏弹窗**：新增或编辑数据时弹窗自动进入全屏，顶部标题栏保留全屏切换按钮，用户可一键退出全屏；退出后支持拖拽标题栏移动弹窗，回到桌面端时恢复之前的窗口大小与位置。
- **横向滚动**：表格区域在窄屏下支持横向滚动，单元格内容不换行，通过原生滚动保证列宽不被压缩。
- **纵向堆叠**：搜索表单的 label 与内容区纵向堆叠，查询条件行垂直排列，每个控件占满整行宽度；工具栏按钮自动换行，分页组件居中并允许换行。
- **布局降级**：若使用动态表单布局，移动端 grid 自动降为 1 列，保证表单项单列纵向展示。

## 可访问性

- 按钮使用语义化标签
- 表单项使用 label 关联
