# Windows UI Admin — 设计文档

## 组件分类
- **分类**：Others（其他）
- **用途**：管理后台模板
- **依赖组件**：WButton, WInput, WForm, WFormItem, WTable, WPagination, WDialog, WDrawer, WMenu, WCard, WTag, WIcon, WBreadcrumb, WLoading, WMessage, WNotification, WEmpty, WSelect, WDatePicker, WRadio, WCheckbox, WSwitch, WDivider, WTabs, WTabPane, WConfigProvider, WSpace, WTimeline

---

## 视觉设计

### 整体布局
- **AdminLayout**：左侧固定侧边栏（220px，折叠时 64px）+ 顶部栏（自适应）+ Tabs 标签栏 + 右侧内容区
- **侧边栏**：XP 风格米色背景（`#ece9d8`），凸起边框，选中项高亮蓝色
- **顶部栏**：XP 标题栏风格，左侧面包屑 + 收起按钮，右侧全屏按钮 + 用户下拉菜单
- **Tabs 栏**：浅灰背景，标签页带关闭按钮，当前页蓝色高亮
- **内容区**：浅灰背景（`#f5f5f5`），内边距 16px

### 登录页
- 居中卡片，宽度 400px
- XP 经典窗口样式：凸起边框 + 阴影
- 蓝色标题栏 "系统登录"
- 表单字段：用户名、密码
- 底部：登录按钮（主色）

### 仪表盘
- 统计卡片行：4 列网格，每卡片展示一个核心指标
- 快捷入口：图标按钮网格
- 最近动态：时间线列表

### CRUD 列表页
- **SearchForm**：顶部查询区域，XP 边框风格
- **操作栏**：新增按钮（左侧）+ 批量删除（左侧）+ 刷新/导出（右侧）
- **Table**：斑马纹、固定操作列、分页器底部居中
- **Form Dialog**：新增/编辑弹窗，表单字段动态生成

### 个人中心
- **基本信息**：表单展示用户名（禁用）、昵称、邮箱、手机号
- **修改密码**：原密码、新密码、确认密码三栏表单
- **系统配置**：表单展示当前语言/主题色/组件大小，点击按钮打开 WDrawer 配置面板
- **配置面板抽屉**：语言切换按钮、主题色选择器、组件大小切换、恢复默认按钮

### 富文本编辑器
- 基于 TinyMCE CDN
- 支持中文语言包
- 工具栏：格式、加粗、斜体、对齐、列表、撤销/重做等

### 错误页面
- **401**：权限不足提示，返回首页按钮
- **404**：页面不存在提示，返回首页按钮

### 多级菜单示例
- **Menu1**：一级子菜单页面
- **Menu2-1 / Menu2-2**：二级子菜单页面，展示三级嵌套导航

## 交互设计

### 登录流程
1. 输入用户名密码 → 点击登录
2. 验证通过 → 存储 Token → 跳转仪表盘
3. 验证失败 → Message 提示错误

### 侧边栏交互
1. 点击菜单项 → 路由跳转 + 菜单高亮
2. 子菜单展开/收起 → 箭头图标切换（arrowDown / arrowRight）
3. 收起侧边栏 → 仅显示图标，文字隐藏，宽度 64px
4. 菜单根据权限动态过滤，无权限菜单不显示

### Tabs 标签页交互
1. 访问新路由 → 自动添加到 Tabs
2. 点击标签 → 切换路由
3. 点击关闭按钮 → 移除标签，自动跳转到左侧标签
4. 右键标签 → 显示上下文菜单：刷新页面 / 关闭当前 / 关闭其他 / 关闭全部
5. 仪表盘标签不可关闭

### 列表页交互
1. 输入查询条件 → 点击查询 → Table 刷新
2. 点击重置 → 清空查询条件 → 刷新列表
3. 点击新增 → 打开 Dialog → 提交后刷新列表
4. 点击编辑 → 打开 Dialog 回填数据 → 提交后刷新
5. 点击删除 → 确认弹窗 → 删除后 Message 成功提示
6. 批量选择 → Checkbox 全选 → 批量删除

### 权限交互
1. 无权限菜单 → 侧边栏不显示
2. 无权限按钮 → 页面内按钮隐藏（`v-if="auth.hasPermission(...)"`）
3. 直接访问无权限路由 → 跳转 401 页面

### 个人中心交互
1. 基本信息页 → 修改表单 → 点击保存
2. 修改密码页 → 填写三栏密码 → 验证一致性 → 点击修改
3. 系统配置页 → 点击「打开配置面板」→ 抽屉弹出 → 修改语言/主题/大小 → 实时生效

## 可访问性

- 所有表单字段关联 `label`
- 按钮有明确的 `aria-label`
- 弹窗聚焦陷阱（focus trap）
- 颜色对比度符合 WCAG 2.1 AA
- 键盘可完全操作

---

## 响应式设计

- **桌面端**（≥1280px）：完整侧边栏 + 顶部栏 + Tabs
- **平板端**（768px–1279px）：侧边栏可折叠，内容区自适应
- **移动端**（<768px）：侧边栏变为抽屉（Drawer），顶部栏简化
