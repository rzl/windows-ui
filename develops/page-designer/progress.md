# WPageDesigner 开发进度

## 状态

已完成

## 实现清单

- [x] 迁移组件库面板、画布、属性面板到组件库
- [x] 支持拖拽与触屏添加组件
- [x] 支持容器嵌套与节点选中/删除/移动
- [x] 属性面板支持文本、统计、图表、表格等组件
- [x] 预览弹窗集成 `WPageRenderer`
- [x] 通过 props 抽象 `loadPage` / `savePage` 业务逻辑
- [x] 文档与示例

## 待优化项

- 属性面板后续可改为 schema 驱动，减少硬编码组件类型判断。
- [x] 支持撤销/重做。
- [x] 支持组件复制与粘贴。
- [x] 表单组件支持页面级 `formData` 绑定。
- [x] 展示组件库新增徽标、步骤条、时间线。
- [x] 事件编辑器支持执行条件与链式动作。
- [x] 画布支持网格辅助线与 Delete 快捷键删除。
- [x] 通过插件机制批量注册大量内置组件（展示 / 表单）。
- [x] 支持子页面配置，用于 `openDialog` 弹窗场景。
- [x] 左侧增加竖向图标按钮组，页面信息放入左侧边栏切换。
- [x] 顶部增加页面管理 tabs，支持主页面/子页面切换、新增与删除。
- [x] 大纲树迁移到左侧边栏。
- [x] 内部组件优先使用 Windows UI 基础组件（按钮、输入框、表单、图标等）。
- [x] 工具栏与节点工具栏操作按钮图标化。
- [x] 组件库支持每行两个、分组收起、搜索过滤、全局尺寸联动。
- [x] 支持深色模式切换。
- [x] 代码拆分为 `usePageHistory` / `usePageSelection` / `usePageDragDrop` composables。
- [x] 属性面板统一使用 Windows UI 表单组件并显式注入全局尺寸。
- [x] 组件库拖拽到容器时正确记录历史并高亮目标区域。
- [x] 画布节点支持拖拽排序，目标位置显示高亮提示。
- [x] 大纲树与画布双向联动：点击大纲选中画布节点、选中嵌套节点自动展开祖先、大纲节点支持拖拽排序。
