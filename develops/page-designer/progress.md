# WPageDesigner 开发进度

## 状态

已完成

## 实现清单

- [x] 迁移组件库面板、画布、属性面板到组件库
- [x] 支持拖拽与触屏添加组件
- [x] 支持容器嵌套与节点选中/删除/移动
- [x] 属性面板支持文本、统计、图表、表格等组件
- [x] 预览弹窗集成 `WPageRenderer`
- [x] 通过 props 抽象 `loadPage` / `savePage` 业务逻辑
- [x] 文档与示例

## 待优化项

- 属性面板后续可改为 schema 驱动，减少硬编码组件类型判断。
- [x] 支持撤销/重做。
- [x] 支持组件复制与粘贴。
- [x] 表单组件支持页面级 `formData` 绑定。
- [x] 展示组件库新增徽标、步骤条、时间线。
- [x] 事件编辑器支持执行条件与链式动作。
- [x] 画布支持网格辅助线与 Delete 快捷键删除。
- [x] 通过插件机制批量注册大量内置组件（展示 / 表单）。
- [x] 支持子页面配置，用于 `openDialog` 弹窗场景。
- [x] 左侧增加竖向图标按钮组，页面信息放入左侧边栏切换。
- [x] 顶部增加页面管理 tabs，支持主页面/子页面切换、新增与删除。
- [x] 大纲树迁移到左侧边栏。
- [x] 内部组件优先使用 Windows UI 基础组件（按钮、输入框、表单、图标等）。
- [x] 工具栏与节点工具栏操作按钮图标化。
- [x] 组件库支持每行两个、分组收起、搜索过滤、全局尺寸联动。
- [x] 支持深色模式（跟随 `WConfigProvider` 全局主题，组件内不再单独管理）。
- [x] 代码拆分为 `usePageHistory` / `usePageSelection` / `usePageDragDrop` composables。
- [x] 属性面板统一使用 Windows UI 表单组件并显式注入全局尺寸。
- [x] 组件库拖拽到容器时正确记录历史并高亮目标区域。
- [x] 画布节点支持拖拽排序，目标位置显示高亮提示。
- [x] 大纲树与画布双向联动：点击大纲选中画布节点、选中嵌套节点自动展开祖先、大纲节点支持拖拽排序。
- [x] 属性编辑防抖记录历史，结构操作先刷新待定变更再记录，撤销粒度更合理。

- 2026-07-04：修复 `WFormItem` 在属性面板中的注入警告。
- 2026-07-04：抽取 `usePageHistory` / `usePageSelection` / `usePageDragDrop` composables，拆分 `page-designer.vue` 代码。
- 2026-07-05：属性面板统一使用 Windows UI 表单组件并显式注入尺寸；修复容器拖拽未记录历史的问题，增加根画布与容器拖拽高亮。
- 2026-07-05：新增 `useNodeTree.moveNodeTo`，支持画布节点与大纲节点的拖拽排序；大纲树自动展开选中节点的祖先容器。
- 2026-07-05：属性编辑采用 300ms 防抖记录撤销历史；所有结构操作（添加、删除、移动、排序、粘贴、应用页面信息）先刷新待定的属性变更再记录，保证撤销顺序正确。
- 2026-10-20：移除组件内部深色模式切换（`mode` prop 与工具栏「深色/浅色」按钮）。原实现默认 `auto` 跟随系统偏好并直接改写全局 `html.dark` 类，会覆盖宿主 `WConfigProvider` 设置的主题且卸载后不恢复；现暗色模式与其他组件一致，由 `WConfigProvider` 统一管理。
- 2026-10-20：新增受限组件面板 `componentGroups` prop（传入后替代内置分组）与 `unregisterComponent` API，支持低代码表单布局设计器等受限场景；修复全屏弹窗被 `max-height: 90vh` 钳制导致底部露出遮罩的问题。
- 2026-10-21：修复 render-component 标签页渲染——此前以名称作为 modelValue 传给 WTabs（tabs 模式按索引解析）导致预览中标签页内容始终不显示；改用名称与索引互转并以作用域插槽按激活页渲染子节点
- 2026-10-21：展示类组件支持字段绑定——统计卡片、文本、图片、徽标、进度条、表格、列表在属性面板配置「绑定字段」后显示值以 formData 为准；GenericRender 渲染的插件表单组件（级联选择、评分、滑块、穿梭框及插件市场自定义组件等）经 props.field 与 formData 双向绑定，与内置表单控件语义一致
